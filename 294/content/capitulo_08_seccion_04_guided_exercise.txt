Trabajo de laboratorio
Solución de problemas de Ansible
Solucionar los problemas que surjan cuando intente ejecutar un playbook que se le
proporcionó.
Resultados
• Solucionar problemas de playbooks.
• Solucionar problemas de hosts gestionados.
Antes De Comenzar
Con el usuario student en la máquina workstation, use el comando lab para preparar su
sistema para este ejercicio.
Este comando prepara su entorno y garantiza que estén disponibles todos los recursos
requeridos.
[student@workstation ~]$ lab start troubleshoot-review
Este comando garantiza que Ansible esté instalado en la máquina workstation. También
crea el directorio /home/student/troubleshoot-review/ y lo completa con los
archivos ansible.cfg, inventory, index.html, secure-web.yml y vhosts.conf.
Instrucciones
En el directorio /home/student/troubleshoot-review, hay un playbook denominado
secure-web.yml. Este playbook contiene un play que se supone que configura Apache
HTTPD con TLS/SSL para los hosts en el grupo webservers. Se supone que el nodo
serverb.lab.example.com es el único host en el grupo webservers en este momento.
Ansible puede conectarse a ese host mediante la cuenta remota devops y las claves SSH que ya
se han configurado. Ese usuario también puede convertirse en root en el host gestionado sin una
contraseña sudo.
Desafortunadamente, existen varios problemas que debe corregir antes de poder ejecutar
correctamente el playbook.
1.
Desde el directorio /home/student/troubleshoot-review, valide la sintaxis del
playbook secure-web.yml. Corrija el problema que se informa.
2.
Valide la sintaxis del playbook secure-web.yml nuevamente. Todavía tiene un problema.
Corrija el problema que se informa.
3.
Valide la sintaxis del playbook secure-web.yml nuevamente. Se detecta otro problema.
Corrija el problema que se informa.
4.
Valide la sintaxis del playbook secure-web.yml por cuarta vez. No debería mostrar errores
de sintaxis.

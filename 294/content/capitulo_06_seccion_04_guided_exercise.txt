Inclusión e importación de archivos
Incluir e importar playbooks y tareas en un playbook de Ansible de máximo nivel.
Resultados
• Incluir archivos de playbooks y tareas en los playbooks.
Antes De Comenzar
Con el usuario student en la máquina workstation, use el comando lab para preparar su
sistema para este ejercicio.

requeridos.

La primera tarea del play debe incluir el primer conjunto de tareas del archivo de tareas
tasks/environment.yml. Defina las variables de tareas necesarias para instalar el
paquete httpd y para habilitar e iniciar el servicio httpd.
La segunda tarea del play debe importar el segundo conjunto de tareas del archivo de
tareas tasks/firewall.yml. Defina las variables necesarias de la tarea para instalar el
paquete firewalld a fin de habilitar e iniciar el servicio firewalld y permitir texto sin
formato y conexiones HTTP seguras.
La tercera tarea del play debe importar el segundo conjunto de tareas del archivo de tareas
tasks/placeholder.yml.
5.1.
Cree la sección de tareas en el primer play agregando la siguiente entrada al playbook
playbook.yml.
  tasks:
5.2.
Incluya el primer conjunto de tareas desde tasks/environment.yml con la
característica include_tasks. Establezca las variables package y service en
httpd.
    - name: Include the environment task file and set the variables
      include_tasks: tasks/environment.yml
      vars:
        package: httpd
        service: httpd
5.3.
Importe el segundo conjunto de tareas desde tasks/firewall.yml con
la característica import_tasks. Establezca las variables firewall_pkg y
firewall_svc en firewalld. Establezca la variable rule en http y https.
    - name: Import the firewall task file and set the variables
      import_tasks: tasks/firewall.yml
      vars:
        firewall_pkg: firewalld
        firewall_svc: firewalld
        rule:
          - http
          - https
5.4.
Importe el último conjunto de tareas desde tasks/placeholder.yml usando la
característica import_tasks. Establezca la variable file en /var/www/html/
index.html.
    - name: Import the placeholder task file and set the variable
      import_tasks: tasks/placeholder.yml
      vars:
        file: /var/www/html/index.html
 6.
Agregue un segundo play al playbook playbook.yml importando el contenido del
playbook plays/test.yml.

6.1.
Agregue un segundo play al playbook playbook.yml para validar la instalación del
servidor web. Importar el play desde plays/test.yml. Establezca la variable url
en http://servera.lab.example.com como variable de play.
- name: Import test play file and set the variable
  import_playbook: plays/test.yml
  vars:
    url: 'http://servera.lab.example.com'
6.2.
El playbook final debería incluir el siguiente contenido:
---
- name: Configure web server
  hosts: servera.lab.example.com
  tasks:
    - name: Include the environment task file and set the variables
      include_tasks: tasks/environment.yml
      vars:
        package: httpd
        service: httpd
    - name: Import the firewall task file and set the variables
      import_tasks: tasks/firewall.yml
      vars:
        firewall_pkg: firewalld
        firewall_svc: firewalld
        rule:
          - http
          - https
    - name: Import the placeholder task file and set the variable
      import_tasks: tasks/placeholder.yml
      vars:
        file: /var/www/html/index.html
- name: Import test play file and set the variable
  import_playbook: plays/test.yml
  vars:
    url: 'http://servera.lab.example.com'
6.3.
Guarde los cambios en el playbook playbook.yml.
 7.
Antes de ejecutar el playbook, ejecute ansible-navigator run -m stdout
playbook.yml --syntax-check para verificar que su sintaxis sea correcta. Corrija los
errores informados antes de pasar al siguiente paso.
[student@workstation projects-file]$ ansible-navigator run \
> -m stdout playbook.yml --syntax-check
playbook: /home/student/projects-file/playbook.yml
 8.
Ejecute el playbook playbook.yml. La salida de ansible-navigator muestra las
tareas y los plays que se importan y el archivo de tareas que se incluye.

Trabajo de laboratorio
Administración de plays y playbooks
complejos
Modificar un playbook complejo para que sea más fácil de gestionar mediante el uso de
patrones de host, inclusiones e importaciones.
Resultados
• Especifique patrones de host para simplificar las referencias de host en un playbook.
• Reestructure un playbook para que las tareas se importen desde archivos de tareas
externos.
Antes De Comenzar
Con el usuario student en la máquina workstation, use el comando lab para preparar su
sistema para este ejercicio.
Este comando prepara su entorno y garantiza que estén disponibles todos los recursos
requeridos.
[student@workstation ~]$ lab start projects-review
Instrucciones
Ha heredado un playbook del administrador anterior de algunos servidores web. El
playbook se usa para configurar un servicio web en servera.lab.example.com,
serverb.lab.example.com, serverc.lab.example.com y serverd.lab.example.com.
En el playbook, también se configura el firewall en los cuatro hosts gestionados para permitir el
tráfico web.
Realice los siguientes cambios en el archivo del playbook playbook.yml para que sea más fácil
de gestionar.
1.
Simplifique la lista de hosts gestionados por el play en el playbook /home/student/
projects-review/playbook.yml usando un patrón de host comodín.
Tiene un segundo playbook, /home/student/projects-review/host-test.yml, que
contiene un play que puede usar para probar los patrones de host antes de usarlos en el play
del playbook playbook.yml.
2.
Reestructure el playbook playbook.yml para que las cuatro primeras tareas del play
se guarden en un archivo de tareas externo ubicado en tasks/web_tasks.yml. Use el
módulo ansible.builtin.import_tasks para incorporar este archivo de tareas en el
play.
3.
Reestructure el playbook playbook.yml para que la quinta, sexta y séptima tareas en su
play se guarden en un archivo de tareas externo ubicado en tasks/firewall_tasks.yml.
Use el módulo ansible.builtin.import_tasks para incorporar este archivo de tareas
en el play.

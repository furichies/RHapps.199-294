Trabajo de laboratorio
Implementación del control de tareas
Instalar el servidor web Apache y protegerlo con el uso de mod_ssl. Usará las condiciones,
los manejadores y el manejo de fallas de tareas en su playbook para implementar el entorno.
Resultados
• Definir condicionales en playbooks de Ansible
• Establecer bucles que realizan iteración de elementos
• Definir manejadores en playbooks
• Manejar errores de tareas.
Antes De Comenzar
Con el usuario student en la máquina workstation, use el comando lab para preparar su
sistema para este ejercicio.
Este comando prepara su entorno y garantiza que estén disponibles todos los recursos
requeridos.
[student@workstation ~]$ lab start control-review

En la máquina workstation, cambie al directorio /home/student/control-review.

required packages are present para instalar la última versión de los paquetes que
faltan. Los paquetes requeridos son especificados por la variable packages, que se define

Resumen
• Los bucles se usan para iterar un conjunto de valores, como una simple lista de cadenas o una
lista de diccionarios.
• Los condicionales se pueden usar para ejecutar tareas o plays únicamente cuando se hayan
cumplido ciertas condiciones.
• Los manejadores son tareas especiales que se ejecutan al final de un play si otras tareas los
notifican.
• Los manejadores solo son notificados cuando una tarea informa que se cambió algo en un host
gestionado.
• Las tareas se pueden configurar para manejar condiciones de error ignorando una falla en las
tareas, forzando a los manejadores a ser invocados aun cuando la tarea haya fallado, marcar una
tarea como con errores cuando fue satisfactoria o reemplazar el comportamiento que hace que
la tarea se marque como modificada.
• Los bloques se usan para agrupar tareas como una unidad y ejecutar otras tareas dependiendo
de si todas las tareas en el bloque se realizaron satisfactoriamente.

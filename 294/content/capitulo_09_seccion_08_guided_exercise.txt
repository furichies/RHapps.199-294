Ejercicio Guiado
Administración del almacenamiento
Asignar un nuevo disco como un volumen físico LVM para un grupo de volúmenes, crea
volúmenes lógicos, los formatea con sistemas de archivos XFS y los monta de forma
inmediata y automática en el momento del arranque en sus hosts gestionados.
Resultados
• Usar el rol redhat.rhel_system_roles.storage para gestionar volúmenes y grupos
de volúmenes de LVM.
• Usar el rol redhat.rhel_system_roles.storage para crear sistemas de archivos.
• Usar el rol redhat.rhel_system_roles.storage para controlar y configurar puntos
de montaje en /etc/fstab.
Antes De Comenzar
Con el usuario student en la máquina workstation, use el comando lab para preparar su
sistema para este ejercicio.
Este comando prepara su entorno y garantiza que estén disponibles todos los recursos
requeridos.
[student@workstation ~]$ lab start system-storage
Instrucciones
Usted es responsable de administrar un conjunto de servidores web. Debe configurarlos
para almacenar los datos del sitio web en un sistema de archivos separado de los archivos de
configuración y de registro para los servidores web. Esta es una práctica recomendada.
Escriba un playbook para lo siguiente:
• Use el dispositivo /dev/vdb como volumen físico LVM, contribuyendo con espacio al grupo de
volúmenes apache-vg.
• Cree dos volúmenes lógicos denominados content-lv (de 64 ) y logs-lv (de 128 MB),
ambos respaldados por el grupo de volúmenes apache-vg.
• Crear un sistema de archivos XFS en ambos volúmenes lógicos.
• Monte el volumen lógico content-lv en el directorio /var/www.
• Monte el volumen lógico logs-lv en el directorio /var/log/httpd.

El playbook final debería incluir el siguiente contenido:
---
- name: Configure storage on webservers
  hosts: webservers
  roles:
    - name: redhat.rhel_system_roles.storage
      storage_pools:
        - name: apache-vg
          type: lvm
          disks:
            - /dev/vdb
          volumes:
            - name: content-lv
              size: 64m
              mount_point: "/var/www"
              fs_type: xfs
              state: present

              size: 128m
              mount_point: "/var/log/httpd"

Administración de la configuración de red
Objetivos
• Configurar los ajustes de red y la resolución de nombres en los hosts gestionados y recopilar
datos de Ansible relacionados con la red.
Configuración de redes con el rol de sistema de red
El rol del sistema redhat.rhel_system_roles.network proporciona una manera de
automatizar la configuración de las interfaces de red y las configuraciones relacionadas con la red
en los hosts gestionados de Red Hat Enterprise Linux.
Este rol soporta la configuración de interfaces Ethernet, interfaces de puente, interfaces
enlazadas, interfaces VLAN, interfaces MACVLAN e interfaces Infiniband e interfaces
inalámbricas.
El rol se configura mediante el uso de dos variables: network_provider y
network_connections.
---
network_provider: nm
network_connections:
  - name: ens4
    type: ethernet
    ip:
      address:
        - 172.25.250.30/24
La variable network_provider configura el proveedor de back end, ya sea nm
(NetworkManager) o initscripts. En Red Hat Enterprise Linux 7 y versiones posteriores, use
nm como proveedor de red predeterminado.
Si aún tiene sistemas Red Hat Enterprise Linux 6 en Extended Lifecycle Support (ELS), debe usar
el proveedor initscripts para esos hosts gestionados. Ese proveedor requiere que el servicio
heredado network esté disponible en los hosts gestionados.
La variable network_connections configura las diferentes conexiones. Toma como valor
una lista de diccionarios, cada uno de los cuales representa configuraciones para una conexión
específica. Use el nombre de la interfaz como nombre de la conexión.

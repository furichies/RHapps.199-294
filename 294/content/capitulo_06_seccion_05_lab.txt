Trabajo de laboratorio
Administración de plays y playbooks
complejos
Modificar un playbook complejo para que sea más fácil de gestionar mediante el uso de
patrones de host, inclusiones e importaciones.
Resultados
• Especifique patrones de host para simplificar las referencias de host en un playbook.
• Reestructure un playbook para que las tareas se importen desde archivos de tareas
externos.
Antes De Comenzar
Con el usuario student en la máquina workstation, use el comando lab para preparar su
sistema para este ejercicio.
Este comando prepara su entorno y garantiza que estén disponibles todos los recursos
requeridos.
[student@workstation ~]$ lab start projects-review
Instrucciones
Ha heredado un playbook del administrador anterior de algunos servidores web. El
playbook se usa para configurar un servicio web en servera.lab.example.com,
serverb.lab.example.com, serverc.lab.example.com y serverd.lab.example.com.
En el playbook, también se configura el firewall en los cuatro hosts gestionados para permitir el
tráfico web.
Realice los siguientes cambios en el archivo del playbook playbook.yml para que sea más fácil
de gestionar.
1.
Simplifique la lista de hosts gestionados por el play en el playbook /home/student/
projects-review/playbook.yml usando un patrón de host comodín.
Tiene un segundo playbook, /home/student/projects-review/host-test.yml, que
contiene un play que puede usar para probar los patrones de host antes de usarlos en el play
del playbook playbook.yml.
2.
Reestructure el playbook playbook.yml para que las cuatro primeras tareas del play
se guarden en un archivo de tareas externo ubicado en tasks/web_tasks.yml. Use el
módulo ansible.builtin.import_tasks para incorporar este archivo de tareas en el
play.
3.
Reestructure el playbook playbook.yml para que la quinta, sexta y séptima tareas en su
play se guarden en un archivo de tareas externo ubicado en tasks/firewall_tasks.yml.
Use el módulo ansible.builtin.import_tasks para incorporar este archivo de tareas
en el play.

Resumen
• Los patrones de host se usan para especificar los hosts gestionados a los que deben apuntar los
plays.
• Puede especificar una lista de múltiples patrones de host en la directiva hosts de un play.
• Puede usar la característica import_playbook para incorporar archivos de play externos a los
playbooks.
• Puede usar la característica include_tasks o import_tasks para incorporar archivos de
tareas externos a los playbooks.
• Cuando incluye contenido, Ansible lo procesa dinámicamente a medida que se alcanza el
contenido. Cuando importa contenido, Ansible lo preprocesa antes de que comience la
ejecución.

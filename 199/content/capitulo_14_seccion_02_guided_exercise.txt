11.3. Edición de archivos de configuración de red 11.3. Edición de archivos de configuración de red Objetivos Modificar la configuración de red editando archivos de configuración. Archivos de configuración de conexión Como alternativa al uso del comando nmcli, puede configurar redes editando directamente los archivos de configuración de conexión. Aunque el comando nmcli es el método preferido para la gestión de perfiles, puede crear o modificar manualmente estos archivos de configuración. Esta alternativa es especialmente útil cuando planeas utilizar archivos de configuración iguales o similares para varios servidores. Los perfiles de conexión de NetworkManager se almacenan en el directorio /etc/NetworkManager/system-connections/. Estos archivos utilizan la sintaxis de archivo de claves, que reemplaza el formato ifcfg obsoleto. Cuando agrega o modifica conexiones mediante el comando nmcli, esos cambios también se almacenan persistentemente en este directorio como archivos que terminan con la extensión .nmconnection. Después de cualquier edición manual, debe utilizar el comando nmcli con reload para recargar los archivos de configuración e informar a NetworkManager de los cambios. Para aplicar los cambios, debe activar manualmente la conexión mediante el comando nmcli con up. Sintaxis de archivos de claves NetworkManager emplea una sintaxis de archivos de claves de estilo INI para sus perfiles de conexión de red. Los elementos de configuración están estructurados en secciones (grupos), y cada configuración se representa como un par clave-valor dentro de estos grupos. Esta sintaxis de configuración ofrece beneficios de legibilidad, como especificar direcciones IP como 192.168.0.1/24 en lugar de matrices de enteros menos intuitivas.

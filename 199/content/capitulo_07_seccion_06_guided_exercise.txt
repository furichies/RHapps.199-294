4.7. Gestión de cuentas de grupos locales 4.7. Administrar cuentas de grupos locales Objetivos Crear, modificar y eliminar cuentas de grupos locales. Administrar grupos locales Puede administrar grupos usando el menú Cuentas en la consola web de RHEL (si está habilitado) o usando herramientas de línea de comandos. Esta sección se centra en las herramientas de línea de comandos que puede usar desde un símbolo del shell, ya sea localmente, a través de una conexión SSH o en la consola web de RHEL. Crear grupos desde la línea de comando El comando groupadd crea grupos. Sin opciones, el comando groupadd utiliza el siguiente número de ID de grupo (GID) disponible del rango que las variables GID_MIN y GID_MAX especifican en el archivo /etc/login.defs. De forma predeterminada, el comando asigna un valor de GID que es mayor que cualquier otro GID existente, incluso si hay disponible un valor inferior. La opción -g del comando groupadd especifica un GID que utilizará el grupo.

root@host:~# groupadd -g 10000 group01
root@host:~# tail /etc/group

...salida omitida...

group01:x:10000:

Nota Debido a que el comando useradd crea automáticamente grupos privados de usuarios con números GID asignados desde 1000 en adelante, algunos administradores reservan un rango especial de números GID altos para usar cuando crean grupos suplementarios para otros fines. Sin embargo, esta administración adicional es innecesaria porque no es necesario que el UID y el GID principal de un usuario sean el mismo número. La opción groupadd comando -r crea grupos de sistemas. Al igual que con los grupos normales, los grupos del sistema utilizan un GID del rango de GID del sistema válidos enumerados en el archivo /etc/login.defs. Los elementos de configuración SYS_GID_MIN y SYS_GID_MAX en el archivo /etc/login.defs definen el rango de GID del sistema.

root@host:~# groupadd -r group02
root@host:~# tail /etc/group

...salida omitida...

group01:x:10000:
group02:x:988:

Modificación de grupos existentes desde la línea de comando El comando groupmod cambia las propiedades de un grupo existente. La opción -n del comando groupmod especifica un nuevo nombre para el grupo.

1.1. Registro de sistemas para soporte de Red Hat 1.1. Registro de sistemas para soporte de Red Hat Objetivos Registre un sistema utilizando su cuenta de Red Hat. Los beneficios de una suscripción a Red Hat Red Hat brinda acceso a repositorios de software a través de Red Hat Content Delivery Network (CDN) en un modelo basado en suscripción. Los repositorios de software proporcionan paquetes actualizados periódicamente, incluidos parches de seguridad, correcciones de errores y mejoras. Los clientes con suscripciones activas pueden acceder a los repositorios de contenido de Red Hat para instalar nuevos paquetes de software y mantenerse actualizados con las últimas actualizaciones. Además de las actualizaciones de software, una suscripción activa proporciona a los clientes recursos técnicos como Customer Portal Labs, soluciones de base de conocimientos, documentación, Red Hat Insights y experiencia en soporte. En 2024, Red Hat hizo la transición a un modelo de suscripción llamado Simple Content Access (SCA). Este modelo de suscripción basado en acceso exige la existencia de una suscripción válida por organización, eliminando la necesidad de adjuntar suscripciones a nivel de sistema. El nuevo modelo reduce la complejidad en la gestión de suscripciones y las herramientas. Como parte de esta migración, los servicios de suscripción de cara al cliente se trasladaron del Portal del cliente de Red Hat (https://access.redhat.com) a Red Hat Hybrid Cloud Console (https://console.redhat.com). Hybrid Cloud Console proporciona una experiencia unificada para la gestión de sistemas y una integración más estrecha con Red Hat Insights. Registro de un sistema RHEL Puede utilizar diferentes opciones para registrar un sistema en el servicio de suscripción de Red Hat. Por ejemplo, puede utilizar la consola web gráfica de RHEL o herramientas de línea de comandos, como la configuración de host remoto (rhc) o el administrador de suscripciones (subscription-manager). Puede utilizar estas herramientas para realizar las siguientes acciones con sus sistemas: Registrar un sistema para asociarlo con una cuenta de Red Hat que tenga una suscripción activa. Durante el registro, el sistema recibe certificados de identidad únicos para la autenticación en el servicio de suscripciones de Red Hat. Habilite repositorios adicionales para proporcionar acceso a paquetes de software según sea necesario. Los repositorios predeterminados se habilitan automáticamente para los productos instalados, lo que proporciona acceso inmediato al contenido. Revise y realice un seguimiento de los derechos disponibles o consumidos en la página Inventario de suscripciones de Hybrid Cloud Console. Opcionalmente, regístrese en Red Hat Insights para obtener análisis predictivos y resolución proactiva de problemas. Registro de un sistema con la herramienta rhc La herramienta de línea de comandos rhc está disponible para registrar sistemas RHEL 8.8 y posteriores. De forma predeterminada, la herramienta rhc habilita

three features: content, analytics and remote-management. These features allow your system to access content

repositorios y habilita los servicios de análisis y remediación de Red Hat Insights con un solo comando. Para utilizar la herramienta rhc, debe autenticarse mediante una cuenta de Red Hat que tenga una suscripción válida. Además, debe tener acceso de root en el sistema para poder registrarlo.

Uso de una clave de activación con la herramienta rhc Para registrar un sistema de forma segura de una manera más automatizada, use el comando rhc connect junto con una clave de activación y el identificador de su organización (identificador numérico). Este método es más seguro que proporcionar nombres de usuario y contraseñas personales. Una clave de activación es un token de autenticación previamente compartido que puede crear y administrar en Hybrid Cloud Console. En el panel, haga clic en Insights for RHEL y luego seleccione Inventario › Configuración del sistema › Claves de activación. Cuando crea una clave de activación, tiene la opción de asociar la clave con la última versión de RHEL o bloquear la clave a una versión anterior específica. Opcionalmente, también puede definir el propósito del sistema, que es un mecanismo de etiquetado para ayudar a identificar los hosts en el inventario más adelante. También puede definir repositorios adicionales para la clave de activación, lo que puede simplificar aún más la configuración de un sistema durante el registro. El siguiente ejemplo muestra cómo utilizar una clave de activación con el comando rhc.

Sin embargo, la herramienta de administración de suscripciones no ha sido reemplazada ni obsoleta en RHEL 10 y continúa funcionando de manera similar a sus versiones anteriores. Inspección de certificados de identidad Un sistema registrado almacena varios certificados en el directorio /etc/pki. Los certificados /etc/pki/product-default identifican los productos de Red Hat que están instalados en el sistema. El par de claves y certificado /etc/pki/consumer identifica el sistema. El certificado /etc/pki/entitlement y el par de claves autentica el sistema en los repositorios. Puede utilizar el comando rct cat-cert para inspeccionar los certificados con más detalle:

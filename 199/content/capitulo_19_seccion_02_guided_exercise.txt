16.3. Ampliación de un volumen lógico 16.3. Ampliación de un volumen lógico Objetivos Aumentar el almacenamiento disponible en un volumen lógico y ampliar su sistema de archivos o espacio de intercambio para utilizar el almacenamiento adicional. Aumente la capacidad de almacenamiento en un volumen lógico Un beneficio de utilizar volúmenes lógicos es aumentar su tamaño sin experimentar tiempo de inactividad. Agregue extensiones físicas gratuitas al LV desde el VG para ampliar la capacidad del LV y ampliar el sistema de archivos. Utilice el comando vgdisplay para confirmar que el grupo de volúmenes tiene suficiente espacio libre para la extensión LV. Utilice el comando lvextend para extender el LV:

root@host:~# lvextend -L +500M /dev/vg01/lv01
  Size of logical volume vg01/lv01 changed from 512.00 MiB (128 extents) to 1012.00 MiB (253 extents).
  Logical volume vg01/lv01 successfully resized.

Este comando aumenta el tamaño del volumen lógico lv01 en 500 MiB. El signo más (+) delante del tamaño significa

adding this value to the existing size; otherwise, without the plus sign, the value defines the final size of the LV.

La opción lvextend del comando -l espera el número de PE como argumento. La opción lvextend del comando -L espera tamaños en bytes, mebibytes, gibibytes o similares. Extender un sistema de archivos XFS al tamaño de volumen lógico El comando xfs_growfs ayuda a expandir el sistema de archivos para ocupar el LV extendido. El sistema de archivos de destino debe ser

mounted before you use the xfs_growfs command. You can continue to use the file system when resizing.

Utilice el comando xfs_growfs para expandir el sistema de archivos XFS:

root@host:~# xfs_growfs /mnt/data/

...salida omitida... los bloques de datos cambiaron de 131072 a 259072 Importante Ejecute siempre el comando xfs_growfs después de ejecutar el comando lvextend. Utilice el lvextend

command -r option to run the two steps consecutively. An XFS file system must be mounted before resizing;

si el sistema de archivos no está montado, la opción -r crea un directorio de punto de montaje temporal para realizar la operación. Alternativamente, después de extender el LV, puede cambiar el tamaño del sistema de archivos usando el comando fsadm. Este comando tiene un alcance más amplio porque admite varios otros sistemas de archivos. Extender un sistema de archivos EXT4 al tamaño de volumen lógico Los pasos para extender LV usando el sistema de archivos ext4 son los mismos que para LV usando el sistema de archivos XFS, excepto por el paso para cambiar el tamaño del sistema de archivos.

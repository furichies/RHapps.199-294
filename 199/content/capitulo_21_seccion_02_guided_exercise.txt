18.2. Ejercicio guiado Recuperar el acceso de superusuario y restablecer la contraseña raíz 18.2. Ejercicio guiado Recuperar el acceso de superusuario y restablecer la contraseña raíz Obtenga acceso administrativo a un sistema cuando la contraseña de superusuario es desconocida o está bloqueada. Resultados Restablecer la contraseña del usuario root. Requisitos previos Como usuario estudiante en la máquina de la estación de trabajo, ejecute el siguiente comando de laboratorio para preparar su entorno para

this exercise, and to ensure that all required resources are available:
student@workstation:~$ lab start rootpw-recover

Instrucciones La contraseña para el usuario root en la máquina del servidor debe ser redhat. Localice la consola de la máquina del servidor e intente iniciar sesión como usuario root. Utilice redhat como contraseña.

servera login: root

Contraseña: redhat Inicio de sesión incorrecto 1. Restablezca la contraseña del usuario root a redhat sin utilizar medios de rescate. Primero, reinicie la máquina del servidor e interrumpa la cuenta regresiva en el menú del cargador de arranque. 2. Ubique la consola del servidor, según corresponda para el entorno de su salón de clases, y luego abra la consola. Envíe Ctrl+Alt+Supr a su sistema utilizando el botón o entrada de menú correspondiente. 2.1. Cuando aparezca el menú del cargador de arranque, presione Esc para interrumpir la cuenta regresiva. 2.2. Edite la entrada resaltada del cargador de arranque del kernel para detener el proceso de arranque justo después de que el kernel monte todos los sistemas de archivos, pero antes de pasar el control a la unidad systemd. 3. Utilice las teclas del cursor para seleccionar la entrada del kernel. 3.1. Presione E para editar la entrada actual. 3.2. Mueva el cursor a la línea que comienza con el texto de Linux. 3.3. Elimine cualquier opción console= de la línea. Importante Si no elimina las opciones console= de la entrada GRUB2 para el kernel de rescate, es posible que el indicador de raíz se inicie en la consola incorrecta y que no pueda acceder a ella. 3.4. Presione Ctrl+E para mover el cursor al final de la línea. 3.5.





18.2. Ejercicio guiado Recuperar el acceso de superusuario y restablecer la contraseña raíz Finalizar En la estación de trabajo, utilice el comando lab para completar este ejercicio. Este paso es importante para garantizar que los recursos de ejercicios anteriores no afecten a los próximos.

student@workstation:~$ lab finish rootpw-recover

Agregue un espacio seguido de la opción init=/bin/bash al final de la línea. Nota Si el texto en la consola es difícil de ver, considere cambiar la resolución al editar la línea del kernel en la entrada del cargador de arranque. Para cambiar la resolución de la consola, agregue el parámetro video=640x480 o vga=ask en la línea que comienza con la palabra linux, después del parámetro rd.break. Para la mayoría de las consolas, un

resolution of 640x480 is enough. By using the vga=ask parameter, you can choose a more suitable

resolución para su entorno. 3.6. Presione Ctrl+X para iniciar usando la configuración modificada. 3.7. Espere a que el sistema termine de iniciarse. En el indicador bash-5.2#, vuelva a montar el sistema de archivos raíz (/) como lectura/escritura. bash-5.2# mount -o remount,rw / 4. Cambie la contraseña de root a redhat. bash-5.2# passwd Nueva contraseña: redhat CONTRASEÑA MALA: La contraseña tiene menos de 8 caracteres Vuelva a escribir la nueva contraseña: redhat

passwd: password updated successfully

5. Configure el sistema para realizar automáticamente un reetiquetado completo de SELinux después del inicio. Este paso es necesario porque el comando passwd recrea el archivo /etc/shadow sin un contexto SELinux. bash-5.2# touch /.autorelabel 6. Reinicie la máquina del servidor. El sistema ejecuta una operación de cambio de etiqueta de SELinux y luego se reinicia automáticamente. Espere a que se inicie la máquina del servidor. bash-5.2# exec /sbin/init 7. Cuando el sistema esté listo, verifique que puede iniciar sesión como usuario root con redhat como contraseña.

servera login: root

Contraseña: redhat ...salida omitida... [root@servera ~]# 8. Cierre la consola del servera. 9.





18.3. Resumen 18.3. Resumen En esta lección, aprendió a recuperar o restablecer la contraseña del usuario root. Puede utilizar la imagen boot.iso como medio de rescate para restablecer la contraseña de root. Inicie en modo de rescate y luego

mount the system in read/write mode. At the shell prompt, change the root directory to the /mnt/sysroot directory

y establezca la contraseña del usuario root. También puede recuperar o restablecer la contraseña de root sin utilizar medios de rescate. Pase la opción init=/bin/bash al kernel y luego vuelva a montar el sistema de archivos raíz en modo lectura/escritura para cambiar la contraseña de raíz. Vuelva a etiquetar todos los archivos en el próximo reinicio para establecer el contexto SELinux correcto.

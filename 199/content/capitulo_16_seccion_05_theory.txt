13.5. Búsqueda e interpretación de entradas de registro del diario del sistema 13.5. Búsqueda e interpretación de entradas de registro del diario del sistema Objetivos Buscar e interpretar entradas de registro en el diario del sistema para revisar el estado del sistema. Buscar eventos en el diario del sistema El servicio systemd-journald almacena datos de registro en un archivo binario estructurado e indexado que se conoce como diario. Estos datos incluyen información adicional sobre el evento de registro. Por ejemplo, para los eventos syslog, esta información incluye la prioridad del mensaje original y la función, que es un valor que el servicio syslog asigna para rastrear el proceso que originó un mensaje. Importante En Red Hat Enterprise Linux, el directorio /run/log basado en memoria contiene el diario del sistema de forma predeterminada. El contenido del directorio /run/log se pierde cuando se apaga el sistema. Puede cambiar el directorio de diario a una ubicación persistente, lo cual se analiza más adelante en esta lección. Para recuperar mensajes de registro del diario, utilice el comando journalctl. Puede utilizar el comando journalctl para ver todos los mensajes del diario o buscar eventos específicos según opciones y criterios. Si ejecuta el comando como usuario root, tendrá acceso completo al diario. Aunque los usuarios habituales también pueden utilizar el comando journalctl, el sistema les impide ver ciertos mensajes.

root@host:~# journalctl

13.5. Búsqueda e interpretación de entradas del registro del diario del sistema La siguiente lista muestra algunos campos del diario del sistema para buscar líneas relevantes para un proceso o evento en particular: _COMM El nombre del comando _EXE La ruta al archivo ejecutable para el proceso _PID El PID del proceso _UID El UID del usuario que ejecuta el proceso _SYSTEMD_UNIT La unidad systemd que inició el proceso Por ejemplo, el siguiente comando journalctl muestra todas las entradas del diario relacionadas con el servicio sshd.service con

the 2188 PID:
root@host:~# journalctl _SYSTEMD_UNIT=sshd.service _PID=2188

09 de junio 12:57:21 estación de trabajo (sshd)[2188]: sshd.service: referenciado pero... 09 de junio 12:57:21 estación de trabajo sshd[2188]: Servidor escuchando en 0.0.0.0 puerto 22. 09 de junio 12:57:21 estación de trabajo sshd[2188]: Servidor escuchando en :: puerto 22. Nota Para obtener una lista de campos de diario, consulte la página del manual systemd.journal-fields(7). Referencias

journalctl(1), systemd.journal-fields(7), and systemd.time(7) man pages

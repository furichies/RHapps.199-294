5.3. Administrar permisos de archivos desde la línea de comandos 5.3. Administrar permisos de archivos desde la línea de comandos Objetivos Cambiar los permisos y la propiedad de los archivos con herramientas de línea de comandos. Cambiar permisos de archivos y directorios En Linux, puede configurar permisos en archivos y directorios para definir acceso específico para diferentes conjuntos de usuarios. La principal utilidad para configurar estos permisos es el comando chmod. El comando chmod significa "cambiar modo",

where mode refers to a file's permissions. The following list shows some key characteristics of the chmod command:

Cambia los permisos de archivos y directorios desde la línea de comando. Se necesita una instrucción de permiso seguida de una lista de archivos o directorios para cambiar. Puede configurar la instrucción de permiso de forma simbólica o en notación octal (numérica). Cambiar permisos con el método simbólico El método simbólico para cambiar permisos de archivos utiliza letras para representar las categorías y permisos de usuario, y símbolos para modificar la configuración de permisos. Utilice el comando chmod para modificar los permisos de archivos y directorios. La sintaxis general es la siguiente:

user@host:~$ chmod Who/What/Which file|directory

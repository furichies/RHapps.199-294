10.5. Servicios de control de laboratorio y demonios 10.5. Servicios de control de laboratorio y demonios Controla y monitorea los servicios del sistema y demonios que inicia systemd. Resultados Habilitar, deshabilitar, iniciar y detener servicios. Requisitos previos Como usuario estudiante en la máquina de la estación de trabajo, ejecute el siguiente comando de laboratorio para preparar su entorno para

this exercise, and to ensure that all required resources are available:
student@workstation:~$ lab start services-review

Instrucciones Evaluación Como usuario estudiante en la máquina de la estación de trabajo, utilice el comando de laboratorio para calificar su trabajo. Corrija cualquier error informado y vuelva a ejecutar el comando hasta que tenga éxito.

student@workstation:~$ lab grade services-review

Finalizar En la estación de trabajo, cambie al directorio de inicio del usuario estudiante y use el comando de laboratorio para completar este ejercicio. Este paso es importante para garantizar que los recursos de ejercicios anteriores no afecten a los próximos.

student@workstation:~$ lab finish services-review

Inicie sesión en la máquina del servidor como usuario estudiante y cambie al usuario raíz. En la máquina del servidor, inicie el servicio psacct. 1. Verificar el estado actual del servicio psacct. Si el servicio psacct está detenido, inícielo. 2. Configure el servicio psacct para que se inicie al iniciar el sistema. 3. Verifique el estado del servicio rsyslog. Si el servicio rsyslog se está ejecutando, deténgalo y verifique que ya no esté activo. 4. Configure el servicio rsyslog para que no se inicie durante el inicio del sistema. 5. Reinicie la máquina del servidor para que la configuración de inicio de los servicios surta efecto. Espere a que la máquina se inicie antes de evaluar esta actividad. La máquina puede tardar unos minutos en iniciarse. 6.

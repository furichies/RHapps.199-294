12.3. Gestión de archivos temporales 12.3. Gestión de archivos temporales Objetivos Configurar software que utilice una unidad de temporizador para programar tareas para borrar archivos temporales en el sistema o para garantizar que existan ciertos archivos o directorios. La herramienta Systemd-tempfiles La mayoría de las aplicaciones y servicios críticos utilizan archivos y directorios temporales. Algunas aplicaciones y usuarios usan el directorio /tmp para almacenar datos de trabajo transitorios, mientras que otras aplicaciones usan ubicaciones específicas de tareas, como directorios volátiles específicos de demonios y usuarios bajo el directorio /run, que existen solo en la memoria. Cuando el sistema se reinicia o se corta la energía, los sistemas de archivos basados ​​en memoria se limpian automáticamente. Normalmente, los demonios y scripts funcionan correctamente sólo cuando existen los archivos y directorios temporales esperados. Además, es necesario eliminar archivos temporales en el almacenamiento persistente para evitar problemas de espacio en disco o datos de trabajo obsoletos. Red Hat Enterprise Linux incluye la herramienta systemd-tmpfiles, que proporciona un método estructurado y configurable para administrar directorios y archivos temporales. Al iniciar el sistema, una de las primeras unidades de servicio systemd que se inicia es el servicio systemd-tmpfiles-setup. Este servicio ejecuta el comando systemd-tmpfiles, que lee las instrucciones de los archivos de configuración /usr/lib/tmpfiles.d/*.conf, /run/tmpfiles.d/*.conf y /etc/tmpfiles.d/*.conf. Estos archivos de configuración enumeran archivos y directorios que el servicio systemd-tmpfiles-setup debe crear, eliminar o proteger con permisos. Limpiar archivos temporales con un temporizador Systemd Para evitar que los sistemas de larga ejecución llenen sus discos con datos obsoletos, una unidad de temporizador systemd llamada systemd-tmpfiles-clean.timer activa a intervalos regulares la unidad systemd-tmpfiles-clean.service, que ejecuta el comando systemd-tmpfiles --clean. La configuración de una unidad de temporizador systemd tiene una sección [Temporizador] para indicar cómo iniciar el servicio con el mismo nombre que el temporizador. Precedencia de archivos de configuración Los archivos de configuración del servicio systemd-tmpfiles-clean pueden existir en tres lugares: /etc/tmpfiles.d/*.conf /run/tmpfiles.d/*.conf /usr/lib/tmpfiles.d/*.conf Utilice los archivos en el directorio /etc/tmpfiles.d/ para configurar ubicaciones temporales personalizadas y para anular los valores predeterminados proporcionados por el proveedor. Los archivos en el directorio /run/tmpfiles.d/ son archivos volátiles, que los demonios normalmente usan para administrar sus propios archivos temporales de tiempo de ejecución. Los paquetes RPM relevantes proporcionan los archivos en /usr/lib/tmpfiles.d/

directory; therefore do not edit these files.





12.3. Administrar archivos temporales Si un archivo en el directorio /run/tmpfiles.d/ tiene el mismo nombre de archivo que un archivo en el directorio /usr/lib/tmpfiles.d/, entonces el servicio usa el archivo en el directorio /run/tmpfiles.d/. Si un archivo en el directorio /etc/tmpfiles.d/ tiene el mismo nombre de archivo que un archivo en los directorios /run/tmpfiles.d/ o /usr/lib/tmpfiles.d/, entonces el servicio usa el archivo en el directorio /etc/tmpfiles.d/. Dadas estas reglas de precedencia, puede anular la configuración proporcionada por el proveedor copiando el archivo relevante al directorio /etc/tmpfiles.d/ y editándolo. Al utilizar estas ubicaciones de configuración correctamente, puede administrar las configuraciones configuradas por el administrador desde un sistema de administración de configuración central, y las actualizaciones de paquetes no sobrescriben sus configuraciones configuradas. Nota Al probar configuraciones nuevas o modificadas, aplique solo los comandos de un único archivo de configuración a la vez. Especifique el nombre del archivo de configuración único en la línea de comando systemd-tmpfiles. Referencias a las páginas man systemd-tmpfiles(8), tmpfiles.d(5), stat(1), stat(2) y systemd.timer(5)

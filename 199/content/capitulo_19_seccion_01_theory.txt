16.1. Creación de volúmenes lógicos 16.1. Creación de volúmenes lógicos Objetivos Describir cómo funciona Logical Volume Manager y utilizar LVM para crear un volumen lógico, formatear el volumen con un sistema de archivos y montar el volumen. Descripción general del Administrador de volúmenes lógicos Utilice el sistema LVM para crear volúmenes de almacenamiento lógicos como una capa en el almacenamiento físico. Este sistema de almacenamiento proporciona mayor flexibilidad que utilizar el almacenamiento físico directamente. LVM oculta la configuración de almacenamiento de hardware del software y le permite cambiar el tamaño de los volúmenes sin detener aplicaciones ni desmontar sistemas de archivos. LVM proporciona herramientas integrales de línea de comandos para administrar el almacenamiento. Dispositivos físicos Los volúmenes lógicos utilizan dispositivos físicos para almacenar datos. Estos dispositivos pueden ser particiones de disco, discos completos, dispositivos de matriz redundante de discos independientes (RAID) o discos de redes de área de almacenamiento (SAN). Debe inicializar un dispositivo como un volumen físico LVM. Un volumen físico LVM debe utilizar todo el dispositivo físico. Volúmenes físicos (PV) LVM utiliza el dispositivo físico subyacente como volumen físico LVM. Las herramientas LVM segmentan los volúmenes físicos en extensiones físicas (PE) para formar pequeños fragmentos de datos que actúan como el bloque de almacenamiento más pequeño en un PV. Grupos de volúmenes (VG) Un grupo de volúmenes es un grupo de almacenamiento formado por uno o más PV. Es el equivalente funcional de un disco completo en almacenamiento físico. Un PV debe asignarse únicamente a un único VG. LVM establece el tamaño del PE automáticamente, aunque es posible especificarlo. Un VG puede constar de espacio no utilizado y varios volúmenes lógicos. Volúmenes lógicos (LV) Los volúmenes lógicos se crean a partir de extensiones físicas libres en un VG y se proporcionan como dispositivo de almacenamiento para aplicaciones, usuarios y sistemas operativos. Los LV son una colección de extensiones lógicas (LE), que se asignan a

extents. By default, each LE is mapped to one PE. Setting specific LV options changes this mapping; for

Por ejemplo, la duplicación hace que cada LE se asigne a dos PE. Flujo de trabajo de Logical Volume Manager La creación de almacenamiento LVM requiere la construcción de estructuras en un flujo de trabajo lógico. Determine los dispositivos físicos que se convertirán en volúmenes físicos e inicialice estos dispositivos como volúmenes físicos LVM. Cree un grupo de volúmenes a partir de varios volúmenes físicos. Cree los volúmenes lógicos a partir del espacio disponible en el grupo de volúmenes. Formatee el volumen lógico con un sistema de archivos y móntelo, actívelo como espacio de intercambio o pase el volumen sin formato a una base de datos o servidor de almacenamiento para estructuras avanzadas.

Utilice el comando udevadm SET para registrar la nueva partición con el kernel.

root@host:~# udevadm settle

Crear volúmenes físicos Utilice el comando pvcreate para etiquetar la partición física como un volumen físico LVM. Etiquete varios dispositivos simultáneamente utilizando nombres de dispositivos delimitados por espacios como argumentos para el comando pvcreate. Este ejemplo etiqueta los dispositivos /dev/sdb1 y /dev/sdb2 como PV que están listos para crear grupos de volúmenes.

root@host:~# pvcreate /dev/sdb1 /dev/sdb2
  Physical volume "/dev/sdb1" successfully created.
  Physical volume "/dev/sdb2" successfully created.
  Creating devices file /etc/lvm/devices/system.devices

Crear un grupo de volúmenes El comando vgcreate crea uno o más volúmenes físicos en un grupo de volúmenes. El primer argumento es el nombre de un grupo de volúmenes, seguido de uno o más volúmenes físicos para asignar a este VG. Este ejemplo crea el VG vg01 utilizando los PV /dev/sdb1 y /dev/sdb2.

root@host:~# vgcreate vg01 /dev/sdb1 /dev/sdb2
  Volume group "vg01" successfully created

Crear un volumen lógico El comando lvcreate crea un volumen lógico a partir de los PE disponibles en un grupo de volúmenes. Utilice el comando lvcreate para configurar el nombre y el tamaño de LV y el nombre de VG para contener este volumen lógico. Este ejemplo crea el LV lv01 con 300 MiB en el VG vg01.

root@host:~# lvcreate -n lv01 -L 300M vg01
  Logical volume "lv01" created.

Este comando puede fallar si el grupo de volúmenes no tiene suficientes extensiones físicas libres. El tamaño LV se redondea al siguiente valor de tamaño PE cuando el tamaño no coincide exactamente. La opción -L del comando lvcreate requiere tamaños en bytes, mebibytes (megabytes binarios) y gibibytes (gigabytes binarios), o similares. La -l minúscula requiere tamaños que se especifican como una cantidad de extensiones físicas. Los siguientes comandos son dos opciones para crear el mismo LV con el mismo tamaño:

lvcreate -n lv01 -L 128M vg01 : Create an LV of size 128 MiB, rounded to the next PE.
lvcreate -n lv01 -l 32 vg01 : Create an LV of size 32 PEs at 4 MiB each, total 128 MiB.

Cree un sistema de archivos en el volumen lógico Especifique el volumen lógico utilizando el nombre tradicional /dev/vgname/lvname o el nombre del asignador de dispositivos del kernel /dev/mapper/vgname-lvname.





16.1. Creación de volúmenes lógicos Utilice el comando mkfs para crear un sistema de archivos en el nuevo volumen lógico.

root@host:~# mkfs -t xfs /dev/vg01/lv01

...salida omitida... Cree un punto de montaje utilizando el comando mkdir.

root@host:~# mkdir /mnt/data

Para que el sistema de archivos esté disponible de forma persistente, agregue una entrada al archivo /etc/fstab. /dev/vg01/lv01 /mnt/data xfs defaults 0 0 Actualice el demonio systemd con el nuevo archivo de configuración /etc/fstab.

root@host:~# systemctl daemon-reload

Monte el LV usando el comando de montaje.

root@host:~# mount /mnt/data/

Nota Puede montar un volumen lógico por nombre o por UUID, porque LVM analiza los PV buscando el UUID. Este comportamiento es exitoso incluso cuando el VG se creó usando un nombre, porque el PV siempre contiene un UUID. Mostrar el estado del componente LVM LVM proporciona varias utilidades para mostrar la información de estado de PV, VG y LV. Utilice los comandos pvdisplay, vgdisplay y lvdisplay para mostrar la información de estado de los componentes LVM. Los comandos pvs, vgs y lvs asociados se usan comúnmente y muestran un subconjunto de información de estado, con una línea para cada entidad. Mostrar información del volumen físico El comando pvdisplay muestra información sobre los PV. Utilice el comando sin argumentos para enumerar información de todos los PV del sistema. Proporcionar el nombre del PV como argumento del comando muestra la información específica del PV. Utilice el comando pvdisplay para mostrar la información del PV /dev/sdb1:

root@host:~# pvdisplay /dev/sdb1

Nombre PV muestra el nombre del dispositivo.





16.1. Creación de volúmenes lógicos Nombre de VG muestra el grupo de volúmenes donde se asigna el PV. Tamaño PV muestra el tamaño físico del PV, incluido el espacio inutilizable. Tamaño PE muestra el tamaño de la extensión física. Free PE muestra el tamaño de PE disponible en el VG para crear LV o ampliar LV existentes.

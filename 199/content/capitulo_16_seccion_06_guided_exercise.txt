13.7. Configuración de un diario del sistema persistente 13.7. Configuración de un diario del sistema persistente Objetivos Configurar un diario del sistema para almacenar de manera persistente los eventos de registro después de un reinicio y rotar los eventos de registro automáticamente. Almacenamiento del diario del sistema De forma predeterminada, Red Hat Enterprise Linux almacena los archivos del diario del sistema en el directorio /run/log/journal y el sistema borra el diario del sistema después de reiniciar. Puede configurar el servicio systemd-journald para mantener los archivos del diario de forma persistente, de modo que pueda revisar los eventos del diario al reiniciar el sistema. Configurar un diario persistente del sistema Configure el servicio systemd-journald de la siguiente manera para conservar los diarios del sistema de manera persistente durante un reinicio: Importante Este servicio funciona porque la configuración predeterminada del parámetro Almacenamiento en la configuración del diario está establecida en Almacenamiento=auto. Este parámetro significa que si el directorio /var/log/journal existe, entonces el almacenamiento persistente se habilita automáticamente, pero si el almacenamiento no se habilita, entonces se usa el almacenamiento volátil en el directorio /run/log/journal. Los archivos de configuración del diario se analizan con más detalle más adelante en esta sección. Revisar las entradas del diario en relación con el tiempo de inicio Aunque los diarios del sistema persisten después de un reinicio, la salida del comando journalctl incluye entradas del inicio actual del sistema así como de los inicios anteriores del sistema. Para limitar la salida a un inicio del sistema específico, use Crear el directorio /var/log/journal.

root@host:~# mkdir /var/log/journal

1. Ejecute el comando journalctl --flush para vaciar el diario actual en el almacenamiento. Si el servicio systemd-journald vacía con éxito el diario actual, entonces el servicio crea subdirectorios en el directorio /var/log/journal.

root@host:~# journalctl --flush

2. El subdirectorio del directorio /var/log/journal tiene caracteres hexadecimales en su nombre largo y contiene archivos con la extensión .journal.

root@host:~# ls /var/log/journal

4ec03abd2f7b40118b1b357f479b3112 3. Los archivos binarios .journal almacenan entradas de diario estructuradas e indexadas.

root@host:~# ls /var/log/journal/4ec03abd2f7b40118b1b357f479b3112

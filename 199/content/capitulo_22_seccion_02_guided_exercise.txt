19.3. Etiquetado de puertos SELinux 19.3. Objetivos del etiquetado de puertos de SELinux Verificar y ajustar las etiquetas de SELinux en puertos de red específicos para que los servicios de red permitidos puedan vincularse a esos puertos para escuchar las conexiones de los clientes. Etiquetado de puertos SELinux Además del contexto de archivos y el etiquetado de tipos de procesos, SELinux etiqueta los puertos de red con un contexto SELinux. SELinux controla el acceso a la red etiquetando los puertos de la red e incluyendo reglas en la política específica de un servicio. Por ejemplo, la política de destino SSH incluye el puerto 22/TCP con la etiqueta de contexto ssh_port_t. En la política HTTP, los puertos predeterminados 80/TCP y 443/TCP utilizan la etiqueta de contexto http_port_t. Cuando un proceso objetivo intenta abrir un puerto para escuchar, SELinux verifica que la política incluya entradas que permitan la vinculación del proceso y el contexto. Luego, SElinux puede impedir que un servicio fraudulento se apodere de los puertos que utilizan otros servicios de red legítimos. Administrar el etiquetado de puertos de SELinux Si un servicio intenta escuchar en un puerto no estándar y el puerto no está etiquetado con el tipo de SELinux correcto, entonces SELinux podría bloquear el intento. Puede corregir este problema cambiando el contexto SELinux en el puerto. Normalmente, la política de destino ya etiqueta todos los puertos esperados con el tipo correcto. Por ejemplo, debido a que el puerto 8008/TCP se usa a menudo para aplicaciones web, ese puerto ya está etiquetado con el contexto http_port_t, que es el tipo de puerto predeterminado para un servidor web. Los puertos individuales se pueden etiquetar con un solo contexto de puerto. Listar etiquetas de puerto Utilice el comando grep para filtrar el número de puerto.

root@host:~# grep gopher /etc/services

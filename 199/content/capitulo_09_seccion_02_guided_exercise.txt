6.3. Instalación y actualización de paquetes con DNF 6.3. Instalación y actualización de paquetes con DNF Objetivos Buscar, instalar y actualizar paquetes de software con DNF. Administrar paquetes de software con DNF A partir de Red Hat Enterprise Linux 9, DNF (Dandified YUM) reemplaza a YUM como administrador de paquetes. Los comandos DNF son funcionalmente iguales que los comandos YUM. Por compatibilidad, los comandos YUM todavía existen como enlaces simbólicos.

to DNF:
user@host:~$ ls -l /usr/bin/yum*

lrwxrwxrwx. 1 raíz raíz 5 7 de febrero de 2025 /usr/bin/yum -> dnf-3 lrwxrwxrwx. 1 raíz raíz 20 23 de enero de 2025 /usr/bin/yum-builddep -> ../libexec/dnf-utils lrwxrwxrwx. 1 raíz raíz 20 23 de enero de 2025 /usr/bin/yum-config-manager -> ../libexec/dnf-utils lrwxrwxrwx. 1 raíz raíz 20 23 de enero de 2025 /usr/bin/yum-groups-manager -> ../libexec/dnf-utils lrwxrwxrwx. 1 raíz raíz 20 23 de enero de 2025 /usr/bin/yumdownloader -> ../libexec/dnf-utils Red Hat recomienda usar el comando dnf. Es posible que parte de la documentación aún haga referencia al comando yum, pero los archivos son el mismo comando vinculado. El comando rpm de bajo nivel se puede utilizar para instalar paquetes, pero no está diseñado para funcionar con repositorios de paquetes ni para resolver dependencias de múltiples fuentes automáticamente. DNF mejora la instalación y las actualizaciones de software basado en RPM. Con el comando dnf, puede instalar, actualizar, eliminar y obtener información sobre paquetes de software y sus dependencias. Puede obtener un historial de transacciones y trabajar con múltiples repositorios de software de Red Hat y de terceros. Los repositorios de BaseOS y Application Stream Red Hat Enterprise Linux 10 distribuye contenido a través de dos repositorios de software principales: BaseOS y Application Stream (AppStream). Tanto BaseOS como AppStream son partes necesarias de un sistema Red Hat Enterprise Linux 10. El repositorio de BaseOS proporciona el contenido principal del sistema operativo para Red Hat Enterprise Linux como paquetes RPM. Los componentes de BaseOS tienen el mismo ciclo de vida que el contenido de versiones anteriores de Red Hat Enterprise Linux. Application Stream contiene partes necesarias del sistema, así como una amplia gama de aplicaciones que anteriormente estaban disponibles como parte de Red Hat Software Collections y otros productos y programas. Cada flujo de aplicaciones tiene un ciclo de vida que es el mismo que Red Hat Enterprise Linux 10 o más corto. Las versiones anteriores de Red Hat Enterprise Linux distribuyen algunos flujos de paquetes para aplicaciones populares como módulos, como los sistemas de gestión de bases de datos. En RHEL 10, Red Hat ya no proporciona módulos DNF en el repositorio de AppStream. Búsqueda de software con DNF El comando de ayuda dnf muestra información de uso. El comando dnf list muestra los paquetes instalados y disponibles.

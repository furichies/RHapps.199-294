Recuperar el acceso de superusuario y restablecer la contraseña raíz Objetivos Obtener acceso administrativo a un sistema cuando la contraseña de superusuario es desconocida o está bloqueada. Restablecer la contraseña raíz desde el cargador de arranque Una tarea que todo administrador del sistema debería poder realizar es restablecer la contraseña perdida de un usuario raíz. Esta tarea es trivial si el administrador todavía está conectado, ya sea como usuario root o como usuario sin privilegios con acceso completo a Sudo. Sin embargo, esta tarea es un poco más compleja cuando el administrador no ha iniciado sesión porque requiere reiniciar el sistema en un estado especial conocido como entorno de rescate o modo de rescate. En Red Hat Enterprise Linux 10, puede ingresar al modo de rescate para cambiar una contraseña de root olvidada usando uno de dos

methods:

Con medios de rescate (recomendado) Sin medios de rescate Con medios de rescate El enfoque recomendado es utilizar medios de rescate, que le permiten iniciar un pequeño entorno Red Hat Enterprise Linux desde medios de instalación, como un CD-ROM o un archivo ISO, en lugar de desde el disco duro del sistema. Para iniciar en modo de rescate, debe poder utilizar uno de los siguientes dispositivos o archivos de medios de instalación para iniciar el

system:

Para una máquina física, utilice medios de instalación como un CD-ROM o un dispositivo flash USB. Para una máquina virtual, utilice archivos ISO. Cuando utilice medios de rescate, asegúrese de que la imagen sea la misma que la del sistema. Por ejemplo, para un sistema RHEL 10, debe utilizar una imagen RHEL 10. Como parte de los medios de instalación de red, Red Hat proporciona una imagen de instalación mínima: Red Hat Enterprise Linux 10.0 Boot ISO. Puede utilizar esta imagen ISO de arranque como medio de rescate para reiniciar el sistema y restablecer la contraseña de root. Para utilizar esta imagen como medio de rescate, siga estos pasos: Reinicie el sistema. 1. Durante el reinicio del sistema, seleccione la imagen boot.iso desde la que iniciar. El proceso para seleccionar medios alternativos desde los que iniciar varía según su entorno. 2. En el menú GRUB2, vaya a Solución de problemas › Rescatar un sistema Red Hat Enterprise Linux. 3.

18.1. Recuperar el acceso de superusuario y restablecer la contraseña raíz sin medios de rescate Como alternativa al uso de medios de rescate, también puede acceder al entorno de rescate configurando el sistema para emular el modo de rescate. Para lograr este estado del sistema, pase la opción init /bin/bash al kernel y luego vuelva a montar el sistema de archivos raíz en modo lectura/escritura. Advertencia Este método es riesgoso y debe realizarse con precaución. El sistema continúa iniciando, realiza un reetiquetado completo de SELinux y luego se reinicia nuevamente. Referencias

dracut.cmdline(7) man page.

¿Cómo cambiar una contraseña de root olvidada o perdida? Reinicie el sistema. 1. Interrumpa la cuenta regresiva del cargador de arranque presionando Esc. 2. Inicie con el argumento init=/bin/bash. 3. En el menú GRUB2, mueva el cursor a la entrada del kernel para iniciar. a. Presione E para editar la entrada seleccionada. b. Mueva el cursor a la línea de comando del kernel (la línea que comienza con el texto de Linux). do. Elimine cualquier opción de console= de la línea. d. Vaya al final de la línea presionando Ctrl+E. mi. Agregue la cadena init=/bin/bash al final después del espacio. F. Presione Ctrl+X para iniciar con los cambios. gramo. Espere a que el sistema termine de iniciarse. 4. El sistema de archivos raíz (/) se monta como de solo lectura. Cambiar la contraseña raíz requiere que el sistema de archivos raíz

be mounted as read/write. Remount the root file system in read/write mode:

bash-5.2# mount -o remount,rw / 5. Establezca una nueva contraseña de root. bash-5.2# passwd 6. Cree el archivo .autorelabel oculto para volver a etiquetar el contexto SELinux en todos los archivos en el siguiente inicio del sistema. bash-5.2# touch /.autorelabel 7. Reinicie el sistema. bash-5.2# ejecutivo /sbin/init 8.

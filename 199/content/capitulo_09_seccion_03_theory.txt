Administrar paquetes de software con DNF A partir de Red Hat Enterprise Linux 9, DNF (Dandified YUM) reemplaza a YUM como administrador de paquetes. Los comandos DNF son funcionalmente iguales que los comandos YUM. Por compatibilidad, los comandos YUM todavía existen como enlaces simbólicos.

Es posible que parte de la documentación aún haga referencia al comando yum, pero los archivos son el mismo comando vinculado. El comando rpm de bajo nivel se puede utilizar para instalar paquetes, pero no está diseñado para funcionar con repositorios de paquetes ni para resolver dependencias de múltiples fuentes automáticamente. DNF mejora la instalación y las actualizaciones de software basado en RPM. Con el comando dnf, puede instalar, actualizar, eliminar y obtener información sobre paquetes de software y sus dependencias. Puede obtener un historial de transacciones y trabajar con múltiples repositorios de software de Red Hat y de terceros. Los repositorios de BaseOS y Application Stream Red Hat Enterprise Linux 10 distribuye contenido a través de dos repositorios de software principales: BaseOS y Application Stream (AppStream). Tanto BaseOS como AppStream son partes necesarias de un sistema Red Hat Enterprise Linux 10. El repositorio de BaseOS proporciona el contenido principal del sistema operativo para Red Hat Enterprise Linux como paquetes RPM. Los componentes de BaseOS tienen el mismo ciclo de vida que el contenido de versiones anteriores de Red Hat Enterprise Linux. Application Stream contiene partes necesarias del sistema, así como una amplia gama de aplicaciones que anteriormente estaban disponibles como parte de Red Hat Software Collections y otros productos y programas. Cada flujo de aplicaciones tiene un ciclo de vida que es el mismo que Red Hat Enterprise Linux 10 o más corto. Las versiones anteriores de Red Hat Enterprise Linux distribuyen algunos flujos de paquetes para aplicaciones populares como módulos, como los sistemas de gestión de bases de datos. En RHEL 10, Red Hat ya no proporciona módulos DNF en el repositorio de AppStream. Búsqueda de software con DNF El comando de ayuda dnf muestra información de uso. El comando dnf list muestra los paquetes instalados y disponibles. Advertencia El comando dnf remove elimina los paquetes enumerados y cualquier paquete que los requiera (y los paquetes que los requieran, etc.). Este comando puede provocar la eliminación inesperada de paquetes, por lo que debe revisar detenidamente la lista de paquetes que se eliminarán. Instalación y eliminación de grupos de software con DNF Con DNF, también puede instalar y eliminar grupos, que son colecciones de software relacionado que se instalan juntos. En Red Hat Enterprise Linux, el comando dnf puede instalar dos tipos de grupos de paquetes. Los grupos regulares son colecciones de paquetes. Los grupos de entornos son colecciones de grupos regulares. Los paquetes o grupos que proporcionan estas colecciones pueden aparecer como obligatorios (deben instalarse si el grupo está instalado), predeterminados (normalmente instalados si el grupo está instalado) u opcionales (no instalados cuando el grupo está instalado, a menos que se solicite específicamente). Similar al comando dnf list, el comando dnf group list muestra los nombres de los grupos instalados y disponibles.

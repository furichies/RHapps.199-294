4.10. Ejercicio guiado Administrar contraseñas de usuarios 4.10. Ejercicio guiado Administrar contraseñas de usuarios Establezca una política de administración de contraseñas para los usuarios y bloquee y desbloquee manualmente las cuentas de usuario. Resultados Forzar un cambio de contraseña cuando el usuario inicia sesión en el sistema por primera vez. Forzar un cambio de contraseña cada 90 días. Configure una cuenta de usuario y contraseñas para que caduquen 180 días a partir del día actual. Requisitos previos Como usuario estudiante en la máquina de la estación de trabajo, ejecute el siguiente comando de laboratorio para preparar su entorno para este ejercicio y garantizar que todos los recursos necesarios estén disponibles.

student@workstation:~$ lab start users-password

Instrucciones En la máquina del servidor, bloquee al usuario operador1 e intente cambiar a ese usuario. 1. Como usuario estudiante en la máquina de la estación de trabajo, inicie sesión en la máquina del servidor como usuario estudiante.

[sudo] contraseña para estudiante: estudiante 1.2. Intente iniciar sesión como usuario operador1. Utilice redhat como contraseña. Este comando debería fallar porque el usuario operador1 está bloqueado.

4.11. Laboratorio Administrar usuarios y grupos locales 4.11. Práctica de laboratorio Administrar usuarios y grupos locales Utilice el acceso de superusuario para administrar usuarios y grupos locales y para administrar políticas de contraseñas locales. Resultados Establecer una política de caducidad de contraseña predeterminada para la contraseña del usuario local. Cree y utilice un grupo complementario para nuevos usuarios. Cree tres usuarios con el nuevo grupo suplementario. Establezca una contraseña inicial para los usuarios creados. Configure los miembros del grupo suplementario para usar el comando sudo para ejecutar cualquier comando como cualquier usuario. Establezca una política de caducidad de contraseña específica del usuario. Requisitos previos Como usuario estudiante en la máquina de la estación de trabajo, ejecute el siguiente comando de laboratorio para preparar su entorno para este ejercicio y garantizar que todos los recursos necesarios estén disponibles.

student@workstation:~$ lab start users-review

Instrucciones Evaluación Como usuario estudiante en la máquina de la estación de trabajo, utilice el comando de laboratorio para calificar su trabajo. Corrija cualquier error informado y vuelva a ejecutar el comando hasta que tenga éxito. Desde la máquina de la estación de trabajo, inicie sesión en la máquina del servidor como usuario estudiante y cambie al usuario raíz. 1. En la máquina del servidor, asegúrese de que los usuarios recién creados deban cambiar sus contraseñas cada 30 días. 2. Cree el grupo de consultores con un GID de 35000. 3. Configure los derechos administrativos para permitir que todos los miembros del grupo de consultores ejecuten cualquier comando como cualquier usuario. Evite utilizar la herramienta de línea de comandos visudo para editar el archivo /etc/sudoers. En su lugar, coloque el archivo de configuración en el directorio /etc/sudoers.d. 4. Cree los usuarios consultor1, consultor2 y consultor3 con el grupo de consultores como grupo complementario. 5. Configure las contraseñas de consultor1, consultor2 y consultor3 en redhat. 6. Configure las cuentas de consultor1, consultor2 y consultor3 para que caduquen a los 90 días a partir del día actual. 7. Cambie la política de contraseñas de la cuenta de consultor2 para requerir una nueva contraseña cada 15 días. 8. Además, obligue a los usuarios consultor1, consultor2 y consultor3 a cambiar sus contraseñas en el primer inicio de sesión. 9. Después de completar las tareas de esta actividad, regrese a la estación de trabajo como usuario estudiante. 10.

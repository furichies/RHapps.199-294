Convenciones de documentos Convenciones de documentos Esta sección describe varias convenciones y prácticas que se utilizan en todos los cursos de capacitación de Red Hat. Advertencias Los cursos de Red Hat Training utilizan las siguientes advertencias: Referencias Las referencias describen dónde encontrar documentación externa relevante para un tema. Nota Las notas son consejos, atajos o enfoques alternativos para la tarea en cuestión. Ignorar una nota no debería tener consecuencias negativas, pero podrías perderte algo que te hace la vida más fácil. Importante Las secciones importantes brindan detalles de información que fácilmente se pasa por alto: cambios de configuración que se aplican solo a la sesión actual o servicios que deben reiniciarse antes de que se aplique una actualización. Ignorar estas advertencias no causará pérdida de datos, pero podría causar irritación y frustración. Advertencia No ignore las advertencias. Ignorar estas advertencias probablemente provocará la pérdida de datos. Uso de inteligencia artificial Esta publicación contiene contenido o medios generados o asistidos por herramientas de inteligencia artificial. Todos los entregables de Red Hat Training tienen autoría principalmente humana y todo el contenido fue revisado por un experto en dominio humano. Lenguaje inclusivo Red Hat Training está revisando actualmente su uso del lenguaje en diversas áreas para ayudar a eliminar cualquier término potencialmente ofensivo. Este proceso es continuo y requiere alineación con los productos y servicios que se tratan en los cursos de capacitación de Red Hat. Red Hat agradece su paciencia durante este proceso.





Introducción Introducción RHCSA Rapid Track Opere, administre y mantenga un sistema Red Hat Enterprise Linux y realice un conjunto básico de tareas de administración del sistema, como instalación, almacenamiento y configuración de red, y administración de software. Objetivos Registre un sistema utilizando su cuenta de Red Hat para obtener los servicios de soporte y el software que proporciona Red Hat. Copie, mueva, cree, elimine y organice archivos desde la línea de comandos. Cree, vea y edite archivos de texto desde la línea de comando. Obtener acceso de superusuario a un sistema; crear, administrar y eliminar usuarios y grupos locales; y administrar políticas de contraseñas locales. Establezca permisos estándar en archivos e interprete los efectos de seguridad de diferentes configuraciones de permisos. Descargue, instale, actualice y administre paquetes de software desde los repositorios de paquetes de Red Hat y DNF. Instale, actualice y utilice el software de escritorio proporcionado desde el catálogo de ecosistemas de Red Hat mediante Flatpak. Acceda a sistemas de archivos en dispositivos de medios extraíbles montándolos en un directorio en la jerarquía del sistema de archivos. Investigar, controlar y finalizar procesos que se ejecutan en un sistema Red Hat Enterprise Linux. Controlar y monitorear los servicios del sistema y los demonios que inicia systemd. Configure interfaces y ajustes de red en servidores Red Hat Enterprise Linux. Programe los programas del sistema que deben ejecutarse de forma recurrente para admitir demonios o funciones del sistema operativo. Localice e interprete registros del sistema para solucionar problemas y garantice marcas de tiempo precisas para los eventos de registro. Proteja los sistemas y administre la seguridad utilizando SELinux. Administre dispositivos de almacenamiento creando particiones, sistemas de archivos y espacios de intercambio desde la línea de comandos. Utilice Logical Volume Manager (LVM) para administrar volúmenes lógicos que pueden contener sistemas de archivos y espacios de intercambio. Administre cómo se inicia el sistema para controlar qué servicios se inician y para solucionar y reparar problemas de tiempo de inicio. Obtenga acceso administrativo a un sistema cuando la contraseña de superusuario sea desconocida o esté bloqueada. Controle las conexiones de red a los servicios mediante el firewall del sistema y los servicios de red que pueden vincularse a puertos particulares mediante SELinux. Acceda al almacenamiento conectado a la red que se proporciona mediante el protocolo Network File System (NFS), ya sea manualmente o mediante el montador automático. Pruebe los conocimientos que adquirió en el curso Red Hat System Administration II (RH134) y prepárese para el examen Red Hat Certified System Administrator (EX200). Audiencia Administradores de sistemas, ingenieros de plataformas, desarrolladores y otros profesionales de TI que tengan un conocimiento básico de la línea de comandos de Linux y busquen aprender tareas clave para administrar un sistema Red Hat Enterprise Linux.

15.3. Gestión del espacio de intercambio 15.3. Gestión de objetivos del espacio de intercambio Crear y activar un espacio de intercambio para complementar la memoria física. Conceptos de espacio de intercambio Un espacio de intercambio es un área de un disco bajo el control del subsistema de administración de memoria del kernel de Linux. El kernel utiliza espacio de intercambio para complementar la RAM del sistema manteniendo páginas inactivas en la memoria. La memoria virtual de un sistema abarca la RAM del sistema combinada y el espacio de intercambio. Cuando el uso de memoria en un sistema excede un límite definido, el kernel busca en la RAM páginas de memoria inactivas asignadas a procesos. El kernel escribe las páginas inactivas en el área de intercambio y reasigna las páginas RAM a otros procesos. Si un programa requiere acceso a una página en el disco, entonces el núcleo localiza otra página de memoria inactiva, la escribe en el disco y recupera la página requerida del área de intercambio. Como las áreas de intercambio están en el disco, el intercambio es lento en comparación con la RAM. Aunque el espacio de intercambio aumenta la RAM del sistema, no considere el espacio de intercambio como una solución sostenible para la RAM insuficiente para su carga de trabajo. Cálculo del espacio de intercambio Los administradores deben dimensionar el espacio de intercambio según la carga de trabajo de la memoria del sistema. Formatear espacio de intercambio El comando mkswap aplica una firma de intercambio al dispositivo. A diferencia de otras utilidades de formateo, el comando mkswap escribe un único bloque de datos al principio del dispositivo y deja el resto del dispositivo sin formato para que el kernel pueda usarlo para almacenar páginas de memoria.

root@host:~# mkswap /dev/sdb2

Configurando swapspace versión 1, tamaño = 244 MiB (255848448 bytes)

no label, UUID=39e2667a-9458-42fe-9665-c5c854605881

Activación del espacio de intercambio Utilice el comando swapon para activar un espacio de intercambio formateado. Utilice el comando swapon con el dispositivo como parámetro, o utilice la opción -a del comando swapon para activar todos los espacios de intercambio enumerados en el archivo /etc/fstab. El comando swapon no activa el espacio de intercambio de forma persistente.

root@host:~# swapon /dev/sdb2

Utilice el comando swapon --show option o el comando free para inspeccionar los espacios de intercambio disponibles.

Si las páginas se escriben en el espacio de intercambio, entonces el comando swapoff intenta mover esas páginas a otros espacios de intercambio activos o nuevamente a la memoria. Si el comando swapoff no puede escribir datos en otros lugares, falla con un error y el espacio de intercambio permanece activo. Activar el espacio de intercambio de manera persistente Cree una entrada en el archivo /etc/fstab para garantizar que un espacio de intercambio permanezca activo durante el inicio del sistema. El siguiente ejemplo muestra una línea típica en el archivo /etc/fstab basada en el espacio de intercambio creado previamente. UUID=39e2667a-9458-42fe-9665-c5c854605881 swap swap defaults 0 0 El ejemplo utiliza el UUID de la partición como primer campo. Cuando formatea el dispositivo, el comando mkswap muestra el UUID de la partición. También puede utilizar el comando lsblk --fs para mostrar el UUID de la partición. Alternativamente, puede usar el nombre del dispositivo en lugar del UUID de la partición. El segundo campo suele estar reservado para el punto de montaje. Sin embargo, para dispositivos de intercambio, a los que no se puede acceder a través de la estructura del directorio, este campo toma el valor del marcador de posición de intercambio. La página de manual fstab(5) utiliza none

placeholder value; however, a swap value provides more informative error messages if something goes wrong.

El tercer campo es el tipo de sistema de archivos. El tipo de sistema de archivos para el espacio de intercambio es swap. El cuarto campo es para opciones. El ejemplo utiliza la opción predeterminada. La opción predeterminada incluye la opción de montaje automático, que activa el espacio de intercambio automáticamente al iniciar el sistema. Los dos últimos campos son la bandera de volcado y la orden fsck. Los espacios de intercambio no requieren una copia de seguridad ni una verificación del sistema de archivos, por lo que estos campos deben establecerse en cero. Cuando agrega o elimina una entrada en el archivo /etc/fstab, ejecute el comando systemctl daemon-reload o reinicie el servidor para que el demonio systemd registre la nueva configuración.

root@host:~# systemctl daemon-reload

Establecer prioridad de espacio de intercambio De forma predeterminada, el sistema utiliza espacios de intercambio en orden de prioridad. El kernel usa el espacio de intercambio de mayor prioridad hasta que está lleno y luego comienza a usar el espacio de intercambio de baja prioridad. La prioridad predeterminada para los espacios de intercambio es baja y los nuevos espacios de intercambio tienen menor prioridad que los espacios de intercambio creados anteriormente. Cuando los espacios de intercambio tienen la misma prioridad, el kernel les escribe en forma circular. Para establecer la prioridad, utilice la opción pri en el archivo /etc/fstab. El kernel utiliza primero el espacio de intercambio con mayor prioridad. La prioridad predeterminada es -2.

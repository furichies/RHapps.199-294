11.3. Edición de archivos de configuración de red 11.3. Edición de archivos de configuración de red Objetivos Modificar la configuración de red editando archivos de configuración. Archivos de configuración de conexión Como alternativa al uso del comando nmcli, puede configurar redes editando directamente los archivos de configuración de conexión. Aunque el comando nmcli es el método preferido para la gestión de perfiles, puede crear o modificar manualmente estos archivos de configuración. Esta alternativa es especialmente útil cuando planeas utilizar archivos de configuración iguales o similares para varios servidores. Los perfiles de conexión de NetworkManager se almacenan en el directorio /etc/NetworkManager/system-connections/. Estos archivos utilizan la sintaxis de archivo de claves, que reemplaza el formato ifcfg obsoleto. Cuando agrega o modifica conexiones mediante el comando nmcli, esos cambios también se almacenan persistentemente en este directorio como archivos que terminan con la extensión .nmconnection. Después de cualquier edición manual, debe utilizar el comando nmcli con reload para recargar los archivos de configuración e informar a NetworkManager de los cambios. Para aplicar los cambios, debe activar manualmente la conexión mediante el comando nmcli con up. Sintaxis de archivos de claves NetworkManager emplea una sintaxis de archivos de claves de estilo INI para sus perfiles de conexión de red. Los elementos de configuración están estructurados en secciones (grupos), y cada configuración se representa como un par clave-valor dentro de estos grupos. Esta sintaxis de configuración ofrece beneficios de legibilidad, como especificar direcciones IP como 192.168.0.1/24 en lugar de matrices de enteros menos intuitivas. Ubicaciones de los archivos de configuración Los archivos de configuración de conexión, que se encuentran en el directorio /etc/NetworkManager/system-connections/, normalmente se denominan nombre.nmconnection, donde nombre corresponde al dispositivo o conexión que controla. NetworkManager organiza sus archivos de configuración en los siguientes directorios: /etc/NetworkManager/system-connections/ Este directorio contiene perfiles de conexión persistentes que los usuarios han creado o modificado. /run/NetworkManager/system-connections/ Este directorio almacena perfiles temporales. Estos perfiles se eliminan automáticamente al reiniciar el sistema.

11.3. Edición de archivos de configuración de red /usr/lib/NetworkManager/system-connections/ Este directorio contiene perfiles de conexión preconfigurados e inmutables. Ejemplos de edición de archivos de configuración El siguiente archivo de muestra configura una conexión IPv4 estática: [conexión]

id=Wired connection 1
uuid=27afa607-ee36-43f0-b8c3-9d245cdc4bb3
type=ethernet
autoconnect=true
interface-name=ens4

[ethernet]

mac-address=00:1A:2B:3C:4D:5E

[ipv4]

method=manual
address1=172.25.0.10/24
gateway=172.25.0.254
dns=172.25.254.254
dns-search=example.com

Para mayor especificidad, la conexión puede incluir la dirección MAC, pero no es obligatorio. En el siguiente escenario, imagine que desea cambiar permanentemente la dirección IP de la conexión static-ens4 de 172.24.250.30 a 172.24.250.40. Para realizar esta tarea editando directamente el archivo de conexión, debe realizar el cambio utilizando un editor de texto, recargar la conexión y luego reactivarla. Primero, verifique la configuración actual de la interfaz. Inicialmente, los comandos ip y nmcli muestran la dirección IP activa 172.25.250.30. Tenga en cuenta que el comando ip muestra información de red en tiempo real, mientras que el comando nmcli con show muestra la configuración persistente que se utiliza durante el inicio del sistema.

root@host:~# ip -4 -br addr show dev ens4

ens4 ARRIBA 172.24.250.30/24

root@host:~# nmcli -f ipv4.addresses con show static-ens4
ipv4.addresses:                         172.24.250.30/24

A continuación, edite el archivo de conexión para cambiar permanentemente la información de la dirección IP. Para abreviar, este ejemplo usa el editor de flujo sed, aunque puedes usar cualquier editor de texto.

root@host:~# sed -i 's/172.24.250.30/172.24.250.40/' \

/etc/NetworkManager/system-connections/static-ens4.nmconnection Para aplicar los cambios del archivo de conexión, use el comando nmcli con reload para indicarle a NetworkManager que

reload the connection:
root@host:~# nmcli con reload

Después de recargar, el comando nmcli con show muestra la nueva dirección IP, pero el comando ip aún muestra la dirección original en la configuración de tiempo de ejecución actual.

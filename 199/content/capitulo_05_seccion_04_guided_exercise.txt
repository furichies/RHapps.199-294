2.5. Coincidencia de nombres de archivos con expansiones de Shell 2.5. Coincidencia de nombres de archivos con expansiones de Shell Objetivos Ejecutar eficientemente comandos que afectan a muchos archivos mediante el uso de funciones de coincidencia de patrones del Shell Bash. Expansiones de la línea de comandos Cuando escribe un comando en el símbolo del shell Bash, el shell procesa esa línea de comandos a través de múltiples expansiones antes de ejecutarla. Puede utilizar estas expansiones de shell para realizar tareas complejas que de otro modo serían difíciles o imposibles. El shell Bash realiza las siguientes expansiones: Expansión de nombre de ruta, que ayuda a seleccionar uno o más archivos mediante coincidencia de patrones. Expansión de llaves, que puede generar múltiples cadenas de caracteres. Expansión de tilde, que se expande a una ruta al directorio de inicio de un usuario. Expansión de variable, que reemplaza el texto con el valor almacenado en una variable de shell. Sustitución de comandos, que reemplaza el texto con la salida de un comando. Expansión de nombres de rutas y coincidencia de patrones La expansión de nombres de rutas, históricamente llamada globalización, es una de las características más útiles de Bash. La expansión del nombre de ruta utiliza comodines, que son metacaracteres que se expanden para coincidir con los nombres de archivo y ruta que está buscando. Como resultado, los comandos pueden actuar sobre un conjunto específico de archivos durante una única ejecución. Esta característica ayuda a los administradores del sistema a administrar muchos archivos. La expansión del nombre de ruta expande un patrón de caracteres especiales que representan comodines o clases de caracteres en una lista de nombres de archivos que coinciden con el patrón. Antes de que el shell ejecute su comando, reemplaza el patrón con la lista de nombres de archivos que coinciden. Si el patrón no coincide con nada, entonces el shell intenta utilizar el patrón como argumento literal para el comando que ejecuta.

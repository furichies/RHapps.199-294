13.9. Mantener la hora sincronizada 13.9. Mantenimiento de objetivos de tiempo sincronizados Mantenga una sincronización horaria precisa mediante el protocolo de tiempo de red (NTP) y configure la zona horaria del sistema para garantizar marcas de tiempo correctas para los eventos registrados. Administrar relojes locales y zonas horarias La sincronización horaria del sistema es fundamental para el análisis de archivos de registro en múltiples sistemas. Para funcionar correctamente, algunos servicios también pueden requerir una sincronización horaria correcta. Las máquinas utilizan NTP para proporcionar y obtener información horaria correcta a través de Internet. Una máquina puede obtener información horaria precisa de servicios NTP públicos, como NTP Pool Project. Otra opción es configurar un sistema para que se sincronice directamente con un reloj de hardware de alta calidad, de modo que pueda proporcionar información horaria precisa a los clientes locales. El comando timedatectl muestra una descripción general de la configuración actual del sistema relacionada con la hora, incluida la hora actual, la zona horaria y la configuración de sincronización NTP del sistema.

user@host:~$ timedatectl
               Local time: Wed 2022-03-16 05:53:05 EDT
           Universal time: Wed 2022-03-16 09:53:05 UTC
                 RTC time: Wed 2022-03-16 09:53:05
                Time zone: America/New_York (EDT, -0400)

Reloj del sistema sincronizado: sí

              NTP service: active
          RTC in local TZ: no

Configuración de la zona horaria del sistema Puede enumerar una base de datos de zonas horarias con la opción list-timezones del comando timedatectl:

user@host:~$ timedatectl list-timezones

La Autoridad de Números Asignados de Internet (IANA) proporciona una base de datos pública de zonas horarias, y el comando timedatectl basa los nombres de las zonas horarias en esa base de datos. La IANA nombra las zonas horarias según el continente u océano y, normalmente, la ciudad más grande dentro de la región de la zona horaria. Por ejemplo, la mayor parte de la zona horaria montañosa de EE. UU. es América/Denver. Algunas localidades dentro de la zona horaria tienen diferentes reglas de horario de verano. Por ejemplo, en Estados Unidos, gran parte del estado

of Arizona is in the US Mountain time zone; however it does not observe daylight saving time. Therefore, much of the

El estado de Arizona utiliza la zona horaria América/Phoenix, que representa correctamente la diferencia horaria. Utilice el comando tzselect para identificar el nombre de zona horaria correcto. Este comando plantea interactivamente al usuario preguntas sobre la ubicación del sistema y genera el nombre de la zona horaria correcta. No cambia la configuración de zona horaria del sistema.

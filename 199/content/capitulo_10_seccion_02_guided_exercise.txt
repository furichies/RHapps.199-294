7.3. Gestionando Aplicaciones desde Flatpak 7.3. Administrar aplicaciones desde Flatpak Objetivos Utilice Flatpak para enumerar, buscar, instalar, actualizar, eliminar y obtener información de metadatos de aplicaciones. Administrar aplicaciones con la CLI de Flatpak Al utilizar los comandos de la CLI de Flatpak, puede enumerar, buscar, instalar, actualizar, eliminar y obtener información de metadatos para las aplicaciones de Flatpak y sus dependencias de tiempo de ejecución. Puede utilizar contenido del repositorio de Red Hat y de repositorios remotos de terceros. Red Hat no admite aplicaciones ni tiempos de ejecución de repositorios remotos de terceros. Identificadores de Flatpak Las aplicaciones y los tiempos de ejecución de Flatpak utilizan identificadores únicos que siguen el formato dominio.organización.Aplicación. Este identificador de tres partes permite a una empresa, desarrollador u organización publicar muchas aplicaciones con un prefijo compartido, como com.company. El último segmento (.App) identifica el nombre de la aplicación. Puedes usar el completo o el corto.

object identifier for Flatpak operations: com.company.App or App.

En algunos escenarios, debe especificar la arquitectura o versión de la CPU, como estable o beta. Puede solicitar estas especificaciones adicionales utilizando el identificador triple de un objeto. El formato de un triple identificador es ID/arquitectura/rama, como por ejemplo org.organization.App/x86_64/stable. En Flatpak, rama se refiere a diferentes versiones del mismo objeto. Puedes dejar en blanco algunas partes del identificador triple para especificar parte del objeto. Por ejemplo, org.organization.App/x86_64// especifica solo la arquitectura y org.organization.App//stable especifica solo la rama. Consulta de repositorios remotos para objetos disponibles El comando de búsqueda flatpak enumera las aplicaciones y tiempos de ejecución coincidentes que están disponibles en todos los repositorios remotos que están habilitados en el sistema. Este comando utiliza metadatos de appstream almacenados en caché que ya se descargaron del repositorio remoto. Si los metadatos almacenados en caché tienen más de un día de antigüedad, los metadatos se actualizan automáticamente cuando se ejecuta el comando. El comando utiliza una palabra clave para encontrar una coincidencia en cualquiera de los atributos de metadatos que define el archivo XML de la aplicación: Nombre de la aplicación o tiempo de ejecución Descripción Identificador de la aplicación Palabra clave que define el desarrollador La palabra clave no distingue entre mayúsculas y minúsculas y devuelve información para las aplicaciones y tiempos de ejecución que coinciden con la consulta.

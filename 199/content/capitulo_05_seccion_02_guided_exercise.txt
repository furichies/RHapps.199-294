2.3. Crear enlaces entre archivos 2.3. Crear vínculos entre archivos Objetivos Crear y comparar el uso de vínculos físicos y vínculos simbólicos para hacer referencia al mismo archivo. Administrar vínculos entre archivos Puede crear varios nombres de archivos que apunten al mismo archivo. Estos nombres de archivos se denominan enlaces. Puede crear dos tipos de vínculos: un vínculo físico o un vínculo simbólico (a veces llamado vínculo blando). Cada tipo de enlace es útil para diferentes casos de uso. Enlaces físicos a archivos Cada archivo comienza con un único enlace físico, desde su nombre inicial hasta los datos del sistema de archivos. Cuando crea un vínculo físico a un archivo, crea otro nombre que apunta a esos mismos datos. El nuevo enlace físico actúa exactamente como el nombre del archivo original. Una vez creado el vínculo, no podrá notar la diferencia entre el nuevo vínculo físico y el nombre original del archivo. Puede determinar si un archivo tiene varios enlaces físicos utilizando el comando ls -l. Un elemento en el resultado de este comando es el recuento de enlaces de cada archivo, que es el número de enlaces físicos que tiene el archivo. En el siguiente ejemplo, el recuento de enlaces del archivo newfile.txt es 1. Tiene exactamente una ruta absoluta, que es la ubicación /home/user/newfile.txt.

user@host:~$ pwd

/casa/usuario

user@host:~$ ls -l newfile.txt

-rw-r--r--. 1 usuario usuario 0 30 de mayo 19:19 newfile.txt Puede usar el comando ln para crear un enlace físico (otro nombre de archivo) que apunte a un archivo existente. el comando

needs at least two arguments: a path to the existing file, and the path to the hard link that you want to create.

El siguiente ejemplo crea un vínculo físico llamado newfile-hlink2.txt en el directorio /tmp para el archivo newfile.txt existente.

user@host:~$ ln newfile.txt /tmp/newfile-hlink2.txt
user@host:~$ ls -l newfile.txt /tmp/newfile-hlink2.txt

-rw-rw-r--. 2 usuario usuario 12 30 de mayo 19:19 /tmp/newfile-hlink2.txt -rw-rw-r--. 2 usuario usuario 12 30 de mayo 19:19 newfile.txt Para determinar si dos archivos están vinculados de forma física, utilice la opción -i del comando ls para enumerar el número de inodo de cada archivo. Si los archivos están en el mismo sistema de archivos y sus números de inodo son los mismos, entonces los archivos son enlaces físicos que apuntan al mismo contenido del archivo de datos. En el siguiente ejemplo, puede verificar que los archivos newfile.txt y /tmp/newfile-hlink2.txt comparten el número de inodo 8924107 en la primera columna del comando ls -il.

Búsqueda de archivos Un administrador del sistema debe poder buscar en los sistemas de archivos archivos que coincidan con criterios específicos. Esta sección analiza

two commands to search for files in the file-system hierarchy:

El comando de localización busca en un índice pregenerado nombres de archivos o rutas de archivos y devuelve los resultados al instante. El comando de búsqueda busca archivos en tiempo real analizando la jerarquía del sistema de archivos. Localización de archivos por nombre El comando de localización busca archivos según el nombre o la ruta al archivo. El comando de localización es rápido porque busca la información de la base de datos mlocate. Sin embargo, esta base de datos no se actualiza en tiempo real y requiere actualizaciones frecuentes para obtener resultados precisos. Esta característica también significa que el comando de localización no busca archivos que se crearon después de la última actualización de la base de datos. La base de datos de localización se actualiza automáticamente todos los días. Sin embargo, el usuario root podría utilizar el comando actualizadob para forzar una actualización inmediata.

root@host:~# updatedb

El comando de localización restringe los resultados para usuarios sin privilegios. Para ver el nombre del archivo resultante, el usuario debe tener permiso de búsqueda en el directorio donde reside el archivo. Por ejemplo, ubique los archivos que el usuario desarrollador puede leer y

Búsqueda de archivos en tiempo real El comando buscar localiza archivos buscándolos en tiempo real en la jerarquía del sistema de archivos. Este comando es más lento pero más preciso que el comando de localización. El comando de búsqueda también busca archivos basándose en criterios distintos del nombre del archivo, como los permisos del archivo, el tipo de archivo, el tamaño o la hora de modificación. El comando de búsqueda busca archivos en el sistema de archivos con la cuenta de usuario que ejecutó la búsqueda. El usuario que ejecuta el comando de búsqueda debe tener permiso de lectura y ejecución en un directorio para examinar su contenido. El primer argumento del comando de búsqueda es el directorio a buscar. Si el comando de búsqueda omite el argumento del directorio, inicia la búsqueda en el directorio actual y busca coincidencias en cualquier subdirectorio. Para buscar archivos por nombre de archivo, use la opción buscar comando -name NOMBRE DE ARCHIVO para devolver la ruta de los archivos que coinciden exactamente con NOMBRE DE ARCHIVO. Por ejemplo, para buscar los archivos sshd_config en el directorio raíz (/), ejecute lo siguiente

command:
root@host:~# find / -name sshd_config

/etc/ssh/sshd_config Nota Para el comando de búsqueda, las opciones de palabras completas usan un solo guión (-), a diferencia de un guión doble (--) para la mayoría de los otros comandos de Linux. Cuando utilice un comodín para buscar, debe utilizar comillas simples alrededor de la cadena a buscar, para evitar que el terminal malinterprete el comodín. /var/spool/mail ...salida omitida... La opción -perm del comando de búsqueda busca archivos con un conjunto de permisos particular. Los valores octales definen los permisos con 4, 2 y 1 para lectura, escritura y ejecución. Los permisos están precedidos por una barra diagonal (/) o un guión (-) para controlar los resultados de la búsqueda. Una barra diagonal (/) antes del permiso octal coincide con archivos donde se establece al menos un permiso para usuario, grupo u otros para ese conjunto de permisos. Una búsqueda de permisos /222 no coincide con un archivo con permisos r--r--r--, pero sí coincide con un archivo con permisos rw-r--r--. Un guión (-) antes del permiso significa que las tres partes de los permisos deben coincidir. En el ejemplo anterior, los archivos con permisos rw-rw-rw- coinciden. También puede utilizar la opción buscar comando -perm con el método simbólico para permisos. ...salida omitida... Búsqueda de archivos según el tamaño La opción -size del comando de búsqueda va seguida de un valor numérico y la unidad busca archivos que coincidan con un tamaño especificado. Utilice la siguiente lista para las unidades con la opción -size del comando de búsqueda: Para kilobytes, utilice la unidad k con k siempre en minúsculas. Para megabytes, utilice la unidad M con M siempre en mayúscula. Para gigabytes, utilice la unidad G con G siempre en mayúscula. Puede utilizar los signos más (+) y menos (-) para incluir archivos que sean más grandes y más pequeños que el tamaño indicado, respectivamente. El siguiente ejemplo muestra una búsqueda de archivos con un tamaño exacto de 10 megabytes:

developer@host:~$ find -size 10M

...salida omitida... El siguiente ejemplo busca archivos con un tamaño de más de 10 gigabytes:

developer@host:~$ find -size +10G

...salida omitida... Este ejemplo busca archivos con un tamaño inferior a 10 kilobytes:

developer@host:~$ find -size -10k

...salida omitida... Importante La opción -size del comando de búsqueda redondea todo a unidades individuales. Por ejemplo, el comando find -size 1M muestra archivos de menos de 1 MB, porque redondea todos los archivos a 1 MB.

Localización de archivos en un sistema de archivos Búsqueda de archivos según el tiempo de modificación La opción -mmin del comando de búsqueda, seguida del tiempo en minutos, busca todos los archivos con contenido que cambió hace n minutos. La marca de tiempo del archivo se redondea hacia abajo y admite valores fraccionarios con el rango +n y -n. El siguiente ejemplo busca todos los archivos cuyo contenido cambió hace 120 minutos:

root@host:~# find / -mmin 120

...salida omitida... El modificador + delante de los minutos busca todos los archivos en el directorio raíz (/) que cambiaron hace más de n minutos. Este

example searches for all files with content that changed more than 200 minutes ago:
root@host:~# find / -mmin +200

...salida omitida... El modificador - busca todos los archivos en el directorio / que cambiaron hace menos de n minutos. El siguiente ejemplo enumera

files that changed less than 150 minutes ago:
root@host:~# find / -mmin -150

...salida omitida... Búsqueda de archivos según el tipo de archivo La opción -type del comando de búsqueda limita el alcance de la búsqueda a un tipo de archivo determinado. Utilice las siguientes banderas para limitar la búsqueda

scope:

Para archivos normales, utilice la bandera f. Para directorios, utilice la bandera d. Para enlaces suaves, utilice la bandera l. Para dispositivos de bloque, use la bandera b. El siguiente ejemplo busca todos los directorios en el directorio /etc:

root@host:~# find /etc -type d

/etc /etc/tmpfiles.d /etc/systemd /etc/systemd/system /etc/systemd/system/getty.target.wants ...salida omitida... Este ejemplo busca todos los enlaces blandos en el directorio /:

root@host:~# find / -type l

...salida omitida... Este ejemplo busca todos los dispositivos de bloque en el directorio /dev:

root@host:~# find /dev -type b

/dev/vda1 /dev/vda La opción de enlaces del comando de búsqueda seguida de un número busca todos los archivos con un recuento de enlaces físicos específico.

Cambia los permisos de archivos y directorios desde la línea de comando. Se necesita una instrucción de permiso seguida de una lista de archivos o directorios para cambiar. Puede configurar la instrucción de permiso de forma simbólica o en notación octal (numérica). Cambiar permisos con el método simbólico El método simbólico para cambiar permisos de archivos utiliza letras para representar las categorías y permisos de usuario, y símbolos para modificar la configuración de permisos. El método simbólico utiliza letras para representar los grupos de permisos: u para usuario, g para grupo, o para otros y a para todos. Con el método simbólico, no es necesario establecer un grupo de permisos completamente nuevo. En su lugar, puede cambiar uno o más de los permisos existentes. Utilice los caracteres más (+) o menos (-) para agregar o eliminar permisos,

respectively, or use the equal sign (=) to replace the entire set for a group of permissions.

Una sola letra representa los permisos en sí: r para lectura, w para escritura y x para ejecución. Puede usar una X mayúscula como indicador de permiso para agregar permisos de ejecución solo si el archivo es un directorio o si la ejecución ya está configurada para usuario, grupo u otro. El siguiente ejemplo muestra el uso del método simbólico para eliminar el permiso de lectura y escritura para grupos y otros en

the document.pdf file:
user@host:~$ chmod go-rw document.pdf

Este ejemplo muestra cómo agregar permiso de ejecución para todos en el archivo myscript.sh:

user@host:~$ chmod a+x myscript.sh

También puede utilizar la opción -R del comando chmod con la opción -X para establecer permisos simbólicamente. Con la opción X del comando chmod, puede configurar el permiso de ejecución (búsqueda) en directorios para que se pueda acceder a su contenido, sin cambiar los permisos en la mayoría de los archivos. Sin embargo, tenga cuidado con la opción X, porque si se establece algún permiso de ejecución en un archivo, la opción X también establece el permiso de ejecución especificado en ese archivo. Por ejemplo, el siguiente comando establece recursivamente el acceso de lectura y escritura del grupo al directorio demodir y su contenido, agregando la ejecución grupal solo donde la ejecución ya está configurada para usuario, grupo u otros.

root@host:# chmod -R g+rwX demodir

Cambiar permisos con el método octal Puede utilizar el comando chmod para cambiar los permisos de archivos con el método octal en lugar del método simbólico. En

the following example, the number sign (#) represents three digits:
user@host:~$ chmod ### file|directory

Con el método octal, puede representar los permisos como un número octal de 3 dígitos (o 4 dígitos, al configurar permisos avanzados). Un solo dígito octal puede representar cualquier valor del 0 al 7. En la representación octal de permisos de 3 dígitos, cada dígito representa un nivel de acceso, de izquierda a derecha: usuario, grupo,

and other. To determine each digit:

Cambio de propiedad de usuario o grupo de archivos y directorios El usuario es propietario del archivo que crea. De forma predeterminada, el propietario del grupo de un archivo nuevo es el grupo principal del usuario que crea el archivo. En Red Hat Enterprise Linux, el grupo principal de un usuario suele ser un grupo privado en el que solo ese usuario es miembro. Para otorgar acceso a un archivo según la membresía del grupo, es posible que deba cambiar el grupo propietario del archivo. Sólo el usuario root puede cambiar el usuario propietario de un archivo. Sin embargo, el propietario del archivo y el usuario raíz pueden establecer la propiedad del grupo. El usuario raíz puede otorgar propiedad del archivo a cualquier grupo, pero los usuarios normales solo pueden cambiar la propiedad del grupo del archivo si son miembros del grupo de destino. Los siguientes ejemplos muestran cómo cambiar la propiedad de archivos y directorios mediante el comando chown (cambiar propietario). Por ejemplo, para otorgar la propiedad del archivo app.conf al usuario estudiante, use el siguiente comando:

root@host:~# chown student app.conf

La opción -R del comando chown cambia recursivamente la propiedad de un árbol de directorios completo. El siguiente comando

grants ownership of the Pictures directory and all files and subdirectories within it to the student user:
root@host:~# chown -R student Pictures

También puede utilizar el comando chown para cambiar la propiedad del grupo de un archivo precediendo el nombre del grupo con dos puntos (:). Por ejemplo, el siguiente comando cambia la propiedad del grupo del directorio Imágenes a administradores:

root@host:~# chown :admins Pictures

Puede utilizar el comando chown para cambiar tanto el propietario como el grupo al mismo tiempo utilizando la sintaxis propietario:grupo. Por ejemplo, para cambiar la propiedad del directorio Imágenes al usuario visitante y a los invitados.

group, use the following command:
root@host:~# chown visitor:guests Pictures

En lugar de utilizar el comando chown, algunos usuarios cambian la propiedad del grupo mediante el comando chgrp. Este comando funciona de manera similar al comando chown, excepto que puede usarlo solo para cambiar la propiedad del grupo y el

colon (:) before the group name is not required.





5.3. Administrar permisos de archivos desde la línea de comandos Importante Es posible que encuentre una sintaxis de comando chown alternativa que separe propietario y grupo con un punto

instead of a colon:
root@host:~# chown owner.group filename

Red Hat recomienda no utilizar esta sintaxis y utilizar siempre dos puntos. Debido a que un punto es un carácter válido en un nombre de usuario, el comando chown podría malinterpretar su intención. El comando podría interpretar el usuario y el grupo como un nombre de archivo. En su lugar, utilice sólo dos puntos cuando configure el usuario y el grupo al mismo tiempo. Referencias a las páginas man ls(1), chmod(1), chown(1) y chgrp(1)

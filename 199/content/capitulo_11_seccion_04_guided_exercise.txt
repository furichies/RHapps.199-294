8.5. Localización de archivos en un sistema de archivos 8.5. Localización de archivos en un sistema de archivos Objetivos Buscar archivos en un sistema de archivos que esté actualmente montado. Búsqueda de archivos Un administrador del sistema debe poder buscar en los sistemas de archivos archivos que coincidan con criterios específicos. Esta sección analiza

two commands to search for files in the file-system hierarchy:

El comando de localización busca en un índice pregenerado nombres de archivos o rutas de archivos y devuelve los resultados al instante. El comando de búsqueda busca archivos en tiempo real analizando la jerarquía del sistema de archivos. Localización de archivos por nombre El comando de localización busca archivos según el nombre o la ruta al archivo. El comando de localización es rápido porque busca la información de la base de datos mlocate. Sin embargo, esta base de datos no se actualiza en tiempo real y requiere actualizaciones frecuentes para obtener resultados precisos. Esta característica también significa que el comando de localización no busca archivos que se crearon después de la última actualización de la base de datos. La base de datos de localización se actualiza automáticamente todos los días. Sin embargo, el usuario root podría utilizar el comando actualizadob para forzar una actualización inmediata.

root@host:~# updatedb

El comando de localización restringe los resultados para usuarios sin privilegios. Para ver el nombre del archivo resultante, el usuario debe tener permiso de búsqueda en el directorio donde reside el archivo. Por ejemplo, ubique los archivos que el usuario desarrollador puede leer y

Debido a que la partición myswap comienza en la posición de 1001 MB, establezca la posición final en 1501 MB para configurar un tamaño de partición de 500 MB. 3.1.

15.5. Laboratorio Administrar almacenamiento básico 15.5. Práctica de laboratorio Administrar almacenamiento básico Cree particiones, formatee particiones con un sistema de archivos o un espacio de intercambio, monte el sistema de archivos y active el espacio de intercambio cuando se inicie el sistema. Resultados Mostrar y crear particiones. Formatee una partición con un sistema de archivos XFS y monte el sistema de archivos de forma persistente. Crea espacios de intercambio y actívalos de forma persistente. Requisitos previos Como usuario estudiante en la máquina de la estación de trabajo, ejecute el siguiente comando de laboratorio para preparar su entorno para

this exercise, and to ensure that all required resources are available:
student@workstation:~$ lab start storage-review

Instrucciones Evaluación Como usuario estudiante en la máquina de la estación de trabajo, utilice el comando de laboratorio para calificar su trabajo. Corrija cualquier error informado y vuelva a ejecutar el comando hasta que tenga éxito. La máquina del servidor tiene varios discos sin usar. Utilice el comando parted para crear una partición GPT llamada backup con un tamaño de 2 GB en el disco /dev/sdb. Dado que el comando dividido requiere el uso de compensaciones, es aceptable un tamaño entre 1,8 GB y 2,2 GB. Etiquete la partición de respaldo con el tipo de sistema de archivos XFS. 1. Formatee la partición de respaldo con un sistema de archivos XFS y monte persistentemente el sistema de archivos en el directorio /backup usando el UUID de la partición. 2. En el disco /dev/sdb, cree dos particiones denominadas swap1 y swap2, ambas con un tamaño de 512 MB. Para ambas particiones, configure el tipo de sistema de archivos para alojar espacios de intercambio. Se acepta un tamaño entre 460 MB y 564 MB. 3. Inicialice los espacios de intercambio swap1 y swap2 y configúrelos para que se activen en el arranque. Establezca el orden de prioridad para que se prefiera la partición swap2 a la partición swap1. Configure el espacio de intercambio swap1 para usar una prioridad de 10 y el espacio de intercambio swap2 para usar una prioridad de 20. 4. Reinicie la máquina del servidor. Confirme que el sistema monta automáticamente la partición de respaldo en el directorio /backup. Además, confirme que el sistema active los espacios de intercambio swap1 y swap2. 5. Después de completar las tareas de esta actividad, regrese a la estación de trabajo como usuario estudiante. 6.
